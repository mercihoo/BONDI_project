# tools — 빌드·검사 스크립트

자산 검사, 빌드 자동화, 환경 재현을 담당한다.
담당 직군: **Infra**

## 여기에 넣는 것

- 자산 검사 스크립트 (파일 존재, 메시 유효성, 면 수·텍스처 예산, manifest 필드)
- 카탈로그 등록 스크립트
- Release 빌드 스크립트
- 환경 재현·모델 다운로드 스크립트

## 사용 범위

실행 전 각 도구 디렉터리의 README에서 입력 형식과 자산 예산을 확인한다.

## CI/CD — 미정

CONTRIBUTING 12절 참조. W1에 파일럿을 돌린 뒤 결정한다.
현재 기준은 **로컬 빌드 + 수동 배포**다.
언리얼 빌드는 CI 구축 난도가 높으므로, 막히면 자산 검사 같은 가벼운 검사만
CI로 돌리는 절충안을 검토한다. (U-12)
