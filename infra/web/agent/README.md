# orient_agent — 자료서버 회전 점검 에이전트

로컬 **Qwen2.5-VL 7B**(Ollama, 무료)가 자료서버의 3D 미리보기를 **눈으로 보고** 유물이
바로 섰는지 판정한다. **고치지 않는다 — 보고만 한다** (2026-09-23 결정). 대신 사람이 그대로
실행할 수 있는 `preview/rebuild` 명령을 제안으로 찍어 준다.

이 프로젝트에서 미리보기가 뒤집힌 사고가 반복됐다(금관 누움 · 굽다리바리/빗살무늬토기 거꾸로,
`orientation_overrides.json` 수동 항목 21개). 그 확인을 사람 눈에서 이 에이전트로 옮긴다.

## 판정 방식 — 절대 방향을 묻지 않는다

처음에는 "이 유물이 바로 서 있나?"를 물었다. **실패했다** — 7B 모델은 옆으로 누운
청자기린장식향로를 확신 0.95 로 "바로 섬"이라고 답했다 (2026-09-28 실측).

같은 그림을 **0/90/180/270° 돌린 네 장을 주고 "바른 것은 몇 번?"** 으로 바꾸니 같은 모델이
정답지 3/3(누운 향로 · 선 표주박 주자 · 선 금관)을 맞혔고, 누운 향로는 **고치는 회전(시계 90°)까지**
골라냈다. 절대 판정은 어려워도 비교 선택은 잘한다.

```
지각    썸네일을 네 방향으로 돌려 보여준다 (회전은 WSL PIL)
판단    바른 그림 번호 선택 → 1번(원본)이 아니면 문제
행동    모델이 고른 회전을 적용한 그림으로 "이제 바로 섰나?" 재확인
재지각  그래도 애매하면 미리보기 GLB 를 받아 정면 렌더로 한 번 더
보고    콘솔 + JSONL + rebuild 제안 (실행은 안 한다)
```

판정이 애매할 때 **스스로 증거를 더 만들어 다시 보는 고리**가 있다 — 고정 파이프라인과 갈리는 지점.

## 등록 경로는 두 개다 — 서로 건드리지 않는다

| | 일반 등록 (원래 경로) | 에이전트 등록 (이 도구) |
| --- | --- | --- |
| 입구 | 웹 업로드 화면 | `orient_agent.py upload` |
| 하는 일 | 사람이 올리고 사람이 확인 | 올리고 → 미리보기 대기 → **회전 자동 점검**까지 |
| 서버 API | `POST /api/artifacts/{id}/restored` | 같은 API — 서버는 그대로 |

## 준비

```
ollama pull qwen2.5vl:7b        # 약 6GB · RTX 4070 8GB 에서 동작
```

파이썬은 표준 라이브러리만 쓴다(설치 없음). 이미지 회전과 GLB 렌더는 WSL `lascomp` 환경
(PIL·pyrender)을 부른다 — WSL 이 없으면 원본 한 장 예/아니오 판정으로만 줄어든다.
Ollama 요청에 `num_ctx 16384` 를 준다 — 기본 4096 은 이미지 토큰이 넘는다(실측 4.2k).
서버 주소는 `infra/web/.env` 의 `SERVER_HOST` 를 읽는다(`.env.example` 참고) — 없으면 `--base http://…` 로 준다.

## 쓰기

```bash
# 카드 점검
python orient_agent.py check "new20260918_02/3d/source"
python orient_agent.py check --all                      # 3D 카드 전부 (개당 수십 초)

# 에이전트 등록: 올리고 곧바로 점검
python orient_agent.py upload new20260918_02 restored.glb \
    --label "LaS-Comp v5" --method "LaS-Comp 제로샷 완성 · tau 0.6" --owner 기여자
```

출력 예:

```
  [★] 금관 · 원본 3D
      판정 누움 · 2라운드 — 2번 그림이 바르다 / 교정본 재확인 통과: 관이 세워져 있다
      제안: curl -X POST "http://$SERVER_HOST/api/preview/rebuild?asset=...&up=Z"  # 후보 1
```

`○` 바로 섬 · `★` 확인 필요 · `?` 판단 불가. 기록은 `logs/orient-YYYYMMDD.jsonl` 에
프롬프트·모델 원문 답·판정·제안이 전부 남는다 (D-19 의 재현성 규칙).

## 전수 실측 (2026-09-28, 3D 카드 175건)

| | 수 | 사람 검수 결과 |
| --- | --- | --- |
| ○ 바로 섬 | 164 | 이상 1건(두상 기욺 의심) 외 정상 |
| ★ 누움·거꾸로 단정 | 3 | **진짜 1** (금동약사불입상 — 실제로 거꾸로 서 있었다) · 오판 2 (동검·대쪽모양 동기) |
| ? 판단 불가 | 8 | 진짜 문제 1(청동 투구 — 뒤집힘) · 기준 없음 6(AIHub 파편·점군) · 정상 1 |

- **단정 오판율 3/167 = 1.8%** (unsure 제외한 단정 중 틀린 것 — 오판 2 + 놓침 의심 1)
- **사람이 볼 카드를 175 → 11 로 줄였고(94%), 진짜 문제 2건이 모두 그 11 안에 있었다**
- 중단·예외 0 (Ollama 5xx 1회 재시도 + 유물 단위 격리)
- 남는 경향: 검·동기처럼 길쭉한 금속기는 회전 비교가 약하다 — 오판 2건이 둘 다 이 유형

## 한계 (정직하게)

- 판정 주체가 7B 로컬 모델이다 — **최종 확인은 사람**. 그래서 고치지 않고 제안만 한다.
- 정답지는 3장뿐이다. `check --all` 을 돌려 보고 오판을 이 문서에 적어 나간다.
- `lying_down` 의 up 후보(Z→X)는 경험칙이다. 제안 명령을 하나 실행하고 다시 `check` 로 확인한다.
- 좌우 대칭 유물의 yaw(옆을 보는 것)는 판정 대상이 아니다 — up/flip 만 본다.
