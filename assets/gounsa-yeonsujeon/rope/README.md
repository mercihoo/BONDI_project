# 고운사 마당 동앗줄 (hanging rope)

`SM_Rope_V4.fbx` — 마당에 하늘에서 내려오는 밧줄. 관람자가 이 줄을 잡아당겼다
놓으면 연수전이 현재본 ↔ 전소 전 원형으로 바뀐다.

## 제원

| | |
|---|---|
| 길이 | 14.00 m (원점 = 손잡는 아래쪽 끝, +Z 방향으로 뻗음) |
| 굵기 | 5.3 ~ 7.5 cm (3로브 꼬임, 평균 지름 6.4 cm) |
| 꼬임 피치 | 22 cm |
| 버텍스 / 삼각형 | 19,061 / 32,012 |
| 링 간격 | 손이 닿는 하단 3 m 는 0.75 cm, 그 위는 6 cm |
| 끝 처리 | 아래 2.2 cm 를 불규칙하게 깎고, 표면 섬유 170 가닥 + 늘어진 올 18 가닥 |

단위는 미터로 저작했고 Blender FBX 내보내기에서 mikktspace 탄젠트를 구웠다.
OBJ 는 탄젠트를 담지 못해 언리얼이 직접 만들어야 하는데, 그때 본체가 검게
렌더되는 문제가 있어 FBX 로 넘긴다.

UV 는 꼬임을 따라 회전하므로 스캔된 가닥 결이 지오메트리 로브와 일치한다.
둘레 방향 2회, 길이 방향 20.5 cm 마다 반복. 끝의 섬유는 스캔 타일에서 따뜻한
밝은 구간(u 0.755~0.870, v 0.722~0.778)만 쓰고 노멀을 위쪽으로 55% 기울여,
얇은 원통이 푸른 환경광을 받아 회색으로 보이던 것을 줄였다.

## 빌드

```
python rope_mesh4.py      # 절차적 생성 -> rope_v4.obj
blender -b -P bl_fbx.py   # mikktspace 탄젠트 구워 SM_Rope_V4.fbx
```

`bl_render.py` / `bl_flat.py` 는 형상과 색을 눈으로 확인하는 렌더용이다.
중간 미리보기 렌더와 폐기한 v1~v3 메시는 저장소에 올리지 않는다.

## 출처

지오메트리는 절차적 생성이다.

텍스처는 **Fab `tangled_rope` (vhnofbds) 4K 스캔**에서 파생:
- 아틀라스 `T_vhnofbds_4K_{B,N,ORM}.png` 의 (2150,1950)-(2750,3150) 구간을 크롭
- wrap-blend 로 이음매 제거 후 512x1024 로 리샘플
- 경계 오차: BaseColor 9.4/11.8 → 4.7/4.5, ORM 25.9/17.3 → 2.6/3.9

Fab 에셋 라이선스에 따른 프로젝트 내 개작물이며, **원본 스캔 자체는 배포하지 않는다.**
