## 라이선스

**① 기록 — 공공누리 제1유형.** 국가유산청에 직접 문의해 회신으로 확인했다 (2026-09-14).

> 문의해 주신 「보물 의성 고운사 연수전」, 「보물 의성 고운사 석조여래좌상」 자료의
> 공공누리 유형은 1유형으로 확인되어 이를 안내드립니다.

제1유형은 출처 표시 조건으로 상업적 이용과 변형이 모두 가능하다. 전시에 출처를 표시한다.

> ⚠️ **glb 외 자료는 유형 미확인이다.** 국가유산청 붙임 PDF 사진, 언론사 사진,
> 개인 촬영 영상 프레임(©외부 제공자 등)은 **공공누리 유형을 확인받지 않았다.**
> 제작 과정의 대조 근거로만 쓰고 **전시·공개물에 넣지 않는다.**

**② 현재 — 우리 저작물.** ①에서 목조부를 제거하고 화재 후 상태를 추정해 만들었다.
①의 파생물이므로 제1유형 출처 표시가 함께 적용된다.
