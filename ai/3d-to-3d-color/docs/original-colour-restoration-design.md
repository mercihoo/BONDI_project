# 제작 당시 색 복원 방법 설계 (CIELAB)

담당: AI · 상태: 설계 초안 (2026-09-07) · 종류: Story (구현 Task는 이 문서 확정 후 분리)

```text
2D 사진 → ① 3D(파손) → 색 맞춤(224) → 요철(222) → ② 3D(복원) → [③ 제작 당시 색 ← 이 문서]
```

입력은 형상이 복원된 GLB(② 산출)와 사진에 맞춘 **현재 상태색** 텍스처, 재질 태그다.
출력은 **제작 당시 색 텍스처**(conserved 기본 / pristine 옵션), **손상 지도·보호 마스크**, 형상 안정화된 메시, provenance JSON이다.

> 명세 원칙. 결과는 "역사적 정답"이 아니라 **검증 가능한 복원 가설**이다(명세 1장). 이 단계 산출은 전부 `ai_inferred`(3.1)이고,
> 손상 지도는 FR-UI-008(복원 영역 분리 표시)의 데이터 소스가 된다.

## 1. 파이프라인 — 보존처리 5단계와 알고리즘 대응

| 단계 | 보존처리 의미 | 알고리즘 | 산출 |
| --- | --- | --- | --- |
| 1 상태조사 | 어디가 원표면이고 어디가 손상인가 | 유효 텍셀 마스크(UV 래스터, `relief_maps.py` 재사용) → 재질 판정 → 건전부 검출(2.1) → 손상 지도(2.2) → 보호 마스크(4) | `mask_valid`, `mask_healthy`, `mask_damage`, `mask_protect`, 재질 태그 |
| 2 부식물 제거 | 표면 위 부식·오염층을 걷어냄 | 손상 텍셀의 색도(a, b)를 건전부 기준으로 이행, 암점 클리닝. **L은 유지** | 중간 텍스처 T₁ |
| 3 재마감 | 원래 마감 상태로 | 재질 프리셋 목표색으로 색도 정합(색 맞춤의 `hue`/`chroma` 재사용). 금속은 PBR 재질값 설정(8절 C). pristine이면 L 평탄화 | 최종 텍스처 T₂, 재질 파라미터 |
| 4 형상 안정화 | 표면 잡음 제거, 형태는 그대로 | Taubin 스무딩 + 정점 이동 클램프(5) | 메시 M′ |
| 5 기록 | 무엇을 근거로 무엇을 바꿨나 | JSON(설정·임계·비율·ΔE·이동 통계), 마스크 PNG, manifest 필드 | `restore_<tag>.json`, 마스크, 비교 그림 |

## 2. 색 복원 알고리즘

### 2.1 건전부(잔존 원표면) 자동 검출 — 조명·노출 불변

텍스처를 CIE Lab로 바꾼 뒤 텍셀마다 **건전도 점수**를 만들고 상위 15 % 분위수를 씨앗으로 잡는다. 절대값 임계를 쓰지 않고 분위수를 쓰는 이유는 사진마다 노출이 달라서다.

| 재질군 | 건전도 점수 s | 뜻 |
| --- | --- | --- |
| 금속(금·금동·청동·은·철) | s = L̂ + w_b · b̂ − w_a · \|â\| | 밝고(L) 노란(b) 잔존면. 은·철은 w_b = 0(무채색) |
| 도자기(청자·백자) | s = L̂ − w_c · ΔE_ab(텍셀, 지배 유약색) | 지배 유약색에 가깝고 밝은 면 |

- 기호 ^은 유효 텍셀 안에서의 **로버스트 정규화**(중앙값 0, MAD 1)다. 조명·노출이 바뀌면 L, b가 함께 움직이므로 정규화 후 점수는 거의 불변이다.
- 지배 유약색은 유효 텍셀의 (a, b) 2D 히스토그램 최빈값(mean-shift). 철화·상감처럼 소수 색은 최빈값에 잡히지 않는다.
- 초기 가중치 w_b = 0.5, w_a = 0.3, w_c = 0.05 — PoC 값을 그대로 쓰고 3절 검증 셋으로 재조정한다.
- 씨앗(상위 15 %) → UV 공간에서 영역 확장(색 거리 ΔE < 6, 유효 텍셀 안, 보호 마스크 제외) → 작은 섬 제거(면적 < 0.1 %) → `mask_healthy`.
- 건전부 비율이 3 % 미만이면 "건전부 부족"으로 표시하고 재질 프리셋만으로 진행한다(전면 부식 청동 등).

### 2.2 손상 지도

`mask_damage = mask_valid − mask_healthy − mask_protect`. 손상 텍셀에는 **연속값 손상도** d ∈ [0, 1]도 남긴다(건전부 색 분포까지의 ΔE를 0~30 mm 구간에서 선형 정규화). d는 VR에서 복원 영역 표시의 농도와 conserved/pristine 사이 블렌드 가중으로 쓴다.

### 2.3 부식물 제거 + 재마감 (conserved 기본)

손상 텍셀 p에 대해:

```text
f(p)  = c + (1 − c) · d(p)                                  # 이행 강도: 하한 c = 0.85 (PoC chroma_strength), 손상도 d로 그 위
a'(p) = (1 − f) · a(p) + f · (a_target + K·(1 − d) · (a(p) − mean_a(damage)))   # 색 편차: 도자기 K 0.15, 금속 0.10, 손상도가 높을수록 0으로 (PoC refinish는 0.25 고정)
b'(p) = 같은 식
L₁(p) = (1 − t) · L(p) + t · (L_target + (L(p) − mean_L) · gain)         # 톤: 표면 평균 L → 재질 L, gain ≤ 1 (PoC tone_strength)
L₂(p) = L₁(p) + s · min(1, 2d) · max(0, env(p) − L₁(p))                  # 탈색(금속): 국소 밝은 표면 포락선까지 끌어올림
L'(p) = L₂(p) + 세부 재부착(원본 고주파 × 0.8·[coh + (1 − coh)(1 − 0.9d)])   # coh = 구조 텐서 일관성(선·무늬 1, 점·구멍 0)
(a', b') ← C ≤ 1.15·L' 로 채도 스케일                                    # 어두운 텍셀은 sRGB에 금색 채도를 못 담음
```

재질군별 기본값(v1.5): 도자기·토기 c 0.85, t 0.8, s 0.7, K 0.15 / 금속 c 0.85, t 0.3, s 1.0(창 1024 px), K 0.10. 무늬는 두 경로로 지킨다: ① 일관성 coh가 높은 고주파는 손상도와 무관하게 재부착, ② 같은 성분으로 만든 노멀맵을 GLB에 넣어 색 텍스처가 평탄해져도 요철로 보이게 한다(222 높이맵 재사용). 균열 제거 시 균열 띠는 ①②에서 제외한다(지운 접합선이 요철로 되살아남, 빗살무늬토기 9/9). `env`는 L을 1/8로 줄여 창 512 px의 90 백분위 필터 + 블러로 구한 "주변 건전 표면 밝기"다.

**v1.0~1.2에서 바뀐 이유(9/9).** 처음 설계는 `L' = L`(명암 완전 보존)과 `a' = a + d·(목표 − 평균)`이었다. 뷰어 검수에서 두 가지가 PoC(8/27)보다 못했다. ① 철화백자: d가 작은 크림색 텍셀이 거의 안 움직여 "안 바뀐 것처럼" 보였다 → PoC의 이행 하한 c 도입. ② 금동 좌상: 부식 얼룩의 명암이 그대로 남아 얼룩덜룩했고, 색 편차를 100 % 남겨 초록·갈색 반점이 남았다 → 톤·탈색·편차 압축. PoC의 전역 톤만으로는 얼룩이 안 지워져 탈색 단계를 새로 넣었다. 명암 보존 원칙은 "형상 음영은 남기고 부식 얼룩은 걷어낸다"로 좁혀졌다. 지표로는 L-SSIM이 금속에서 0.999 → 0.58로 떨어지는데, 이는 의도된 변화다(얼룩 제거). 검증 지표(7절)에서 L-SSIM 기준은 도자기에만 둔다.

- `a_target, b_target`은 3절 규칙대로 정한다: 건전부가 3 % 이상이고 프리셋과 타당성 임계 T 이내면 `0.38 × 건전부 중앙값 + 0.62 × 프리셋`(PoC `preset_blend`), 아니면 프리셋. T는 재질별로 금·금동 25, 나머지 15. 건전부가 프리셋에서 T 이상 멀면 밝은 녹청·오염으로 보고 건전부 마스크를 "프리셋과 ΔE 10 이내인 텍셀"로 다시 잡는다.
- 암점 클리닝: 손상 영역 안에서 L이 국소 중앙값보다 15 이상 어두운 작은 점(반경 ≤ 3 px)은 국소 중앙값으로 채운다. 큰 어두운 영역은 음영일 수 있으니 건드리지 않는다.
- 건전부 텍셀은 바꾸지 않는다(d = 0). 보호 마스크 텍셀도 바꾸지 않는다.
- **pristine 옵션**: 위에 더해 L을 건전부 L 분포에 맞춘다(quantile 매핑). 발표용 "새것 같은 모습" 비교 이미지에만 쓰고 기본 산출이 아니다. 건전부가 3 % 미만이면 기준 분포가 없어 **생성하지 않는다**(부식 금속에서 평평한 겨자색이 나옴, 9/9 확인).
- 금속은 3절 PBR 값을 함께 설정한다. base color만 바꾸고 metallic·roughness를 그대로 두면 렌더에서 "칠한 금색"처럼 보인다(224 검증에서 확인). 출력 GLB에는 위치 기준으로 다시 계산한 부드러운 정점 노멀을 넣는다. 스캔 OBJ의 면 노멀은 삼각화·UV 분할 뒤 갈라져 있어 금속 재질에서 삼각형이 그대로 드러난다(9/9 뷰어에서 확인).

### 2.4 색 맞춤(224)과의 관계

224는 "사진의 현재 색"으로, 227은 "제작 당시 색"으로 옮기는 단계다. 같은 Lab 이행 코드(`transfer_*`)를 쓰되 목표만 다르다. 두 텍스처를 모두 보존해 VR에서 현재 ↔ 제작 당시를 전환한다(8절 E).

## 3. 재질 프리셋 — 초기값과 근거 확보 계획

**목표색 결정 규칙(PoC + 타당성 관문).** 건전부가 3 % 이상이고 그 색이 프리셋과 타당성 임계 T 이내면 `0.38 × 건전부 중앙값 + 0.62 × 프리셋`, 아니면 프리셋. **건전부 색이 프리셋에서 T 이상 멀면 그것은 밝은 녹청·오염이지 원표면이 아니다.** v1 청동검에서 밝은 녹청이 건전부로 잡혀 목표색이 (0, 6)이 됐던 사례(ΔE 49)로 추가한 규칙이다. T는 재질별이다: 금·금동은 부식이 녹청으로 가지 않으므로 25(PoC 회귀에서 원표면이 15.2·20.1 떨어져 있었음), 청동·철·도자기는 15. PoC에는 이 관문이 없어 lkh000002 같은 청동은 녹청이 목표에 섞였다.

**근거 확보 방법(우선순위).**

1. **같은 유물의 건전부 실측** — 언제나 1순위. 프리셋은 건전부가 없을 때의 대체값.
2. **참조 코퍼스 통계** — e뮤지엄·박물관 공개 사진 중 상태 양호 유물 N점을 재질·시기별로 모아 배경(중성 회색)으로 노출을 정규화한 뒤 Lab 분포(평균·표준편차)를 뽑는다. 프리셋을 값 하나가 아니라 **분포 + 불확실도**로 바꿀 수 있다(8절 D).
3. **문헌** — 국립문화재연구원 보존처리 보고서의 색차계(L*a*b*) 측정치, 유약 재현 연구. 있으면 최우선 반영.

## 5. 형상 안정화 — 최소 개입

- Taubin 스무딩 λ = 0.5, μ = −0.53, 10회. 라플라시안 스무딩과 달리 부피 수축이 거의 없다.
- 메운 자리의 무늬(v1.7): 메우기는 표면을 매끈하게 만들므로 무늬가 끊긴다. 띠(기본 3 mm)의 고주파를 띠 가장자리 바깥의 대칭 텍셀에서 복사해 색과 요철 둘 다 되살리고, 요철은 띠 정점을 법선 방향으로 밀어(상한 0.6 mm) 기하에도 새긴다. 복사 원본은 같은 UV 조각으로 제한한다(옆 파편 무늬 방지). 결손부에 대한 이 복원은 **추정**이므로 기록(6절)에 `pattern_mirror`로 남긴다.
- 접합선·균열 홈(v1.6/1.7): 스무딩이 아니라 **메우기**. 마스크 정점 + 2링을 자유 변수로 두고 나머지를 고정한 채 min ‖L x‖²(그래프 라플라시안, 쌍조화)로 푼다. 구멍 메우기와 같은 연산이라 홈·턱이 C¹로 이어진다. 상한은 균열용 대각선 2 %. 토기 ssu022891: 접합선 이면각 12° → 2.8°(그 외 7.7°), 이동 평균 0.8 mm.
- **정점 이동 상한 = bbox 대각선 × 0.0007**(91 cm 불상 기준 0.77 mm). 상한을 넘는 이동은 방향을 유지한 채 클램프한다.
- 보호 마스크(음각·투각 경계)에 해당하는 정점은 이동 0.
- 기록: 이동 거리 평균·95 %·최대, 클램프된 정점 비율, 부피 변화율(< 0.1 % 확인).
- 이 단계는 ②에서 넘어온 형상의 표면 잡음 정리용이다. 결손 채움·형태 변경은 ②의 몫이고 여기서 하지 않는다.

## 8. 대안·개선안 — 더 나은 결과가 기대되는 설계

규칙 기반은 설명 가능하고 재현되지만 "색이 밝은 장식"과 "표면 무늬"에서 한계가 확인됐다. 아래 순서로 얹으면 결과가 눈에 띄게 좋아질 것으로 본다. **A와 C를 먼저 권한다.**

### A. 손상/장식 의미론적 세그멘테이션 (PoC 교훈 1순위) — 권장 1

- 무엇: 4절 규칙 마스크를 세그멘테이션 모델로 교체. 클래스 = 건전 / 부식·오염 / 장식(상감·안료·도금) / 결손 경계.
- 어떻게: ① 렌더 뷰 기반 — 모델을 6~12 방향으로 렌더해 SAM 2로 분할하고 CLIP 텍스트 프롬프트("corrosion", "gilding", "inlay", "glaze")로 라벨링 후 UV로 역투영. 아틀라스에서 직접 분할하는 것보다 문맥이 살아 정확하다. ② PoC가 만든 10유물의 규칙 마스크를 **약지도(pseudo-GT)** 로 삼아 소형 U-Net을 파인튜닝. PoC 문서가 이미 "프로토타입 = 데이터 생성기"로 정의한 경로.
- 기대: 터키석 상감 오염색 같은 실패 제거, 조명 변화에 분위수보다 강건.
- 비용: 8 GB에서 SAM 2 추론 가능. 라벨링 3유물 반나절. 위험은 라벨 부족 → 규칙 마스크와 앙상블(둘 다 장식이라 하면 보호)로 시작.

**A 착수 기록(9/10, 1단계 반자동).** `segment_masks.py`, SAM 2 `sam2.1_b`, 텍스처 아틀라스 2K에서 박스 프롬프트. 청자 마모부(덩어리)는 자동 프롬프트로 유효 면적 0.45 %를 잡아 `--wear-mask`로 연결됨. 토기 파편 안쪽 접합선(폭 3~5 px, 거친 결)은 SAM 2가 객체로 보지 않아 사람이 그은 선이 마스크의 골격이 됨. 점 프롬프트는 차트 전체를 선택하므로 금지, 박스만 사용. 다음 단계: 뷰어에서 클릭 → 프롬프트 JSON 생성, CLIP 라벨은 마모·상감 덩어리에만 적용, 균열은 전용 검출(균열 세그멘테이션 모델 또는 메시 홈)로 분리.

**A 2단계(9/10, 붓).** 자동 검출이 장식과 갈라지지 않는다는 결론(G항)에 따라, 뷰어에 마스크 붓을 넣었다. 모델 위 좌드래그가 클릭 지점의 UV에 기록되어 4096² 마스크가 되고, `serve_viewer.py`가 `out_restore/mask_paint/<키>_paint.png`로 저장한다. 그대로 `--crack-mask`에 넣으면 v1.7이 그 자리를 메우고 이웃 결로 무늬를 되살린다. 파편 경계를 넘는 드래그는 아틀라스에서 도약하므로 획을 끊는다. 이로써 8-A의 반자동 경로는 SAM 2(덩어리) + 붓(가는 균열) 두 갈래가 된다.

### B. 재질 조건부 텍스처 재합성으로 "재마감" 대체 — 권장 3 (시간 남으면)

- 무엇: 부식 영역의 **표면 무늬**(문양 연속성, 유약 결)를 건전부에서 가져와 다시 그린다. 색도 이행은 색만 바꾸고 무늬는 부식 상태 그대로 남는다는 한계를 넘는다.
- 어떻게: 1차 PatchMatch 계열 예제 기반 합성(건전부 패치 → 손상부), 2차 diffusion inpainting(렌더 뷰 + 재질 프롬프트 + ControlNet 깊이/노멀 → 역투영).
- 위험: 환각. 반드시 `mask_damage` 안에서만, 산출은 `ai_inferred`로 별도 표시. 명세의 "추정 비중이 커진다" 문구에 정확히 해당하는 단계라 UI 표기가 전제.

### C. 금속은 색이 아니라 **재질(PBR)** 을 복원 — 권장 2 (비용 낮고 효과 큼)

- 무엇: 금·금동·청동·은·철의 "제작 당시"는 base color만이 아니라 **금속 반사율(F0)·거칠기** 상태다. 224 검증에서 base color만 바꾸면 "칠한 금색"으로 보였다.
- 어떻게: 재질 프리셋에 metallic(1.0)·roughness(마감별 0.2~0.55)를 넣고, 건전부는 알갱이 요철(222 노멀맵)을 유지하며 손상부의 roughness를 건전부 값으로 낮춘다. 금동은 도금부/노출부 2클래스로 metallic 텍스처를 나눈다.
- 기대: UE5에서 실제 금속처럼 빛을 받는다. 이 프로젝트의 최종 출력이 PBR GLB라 가장 직접적인 개선.

### C′. 회전체는 형상을 새로 만들고 무늬를 전사 — 착수 9/10 (`idealize_revolution.py`)

**왜.** 접합 복원된 토기는 접합선이 색보다 **기하**(홈·턱, 이면각 12° vs 7.7°)로 남고, 스캔 메시를 고치는 방식(v1.6 쌍조화 메우기)은 파편 안쪽 균열까지 사람이 마스크를 그려야 한다. 회전체 그릇은 축 + 반지름 곡선 하나로 제작 당시 형상이 정해지므로, 매끈한 새 메시를 만들고 스캔의 색·새김 요철만 원통 좌표로 전사하면 접합선·균열·결손이 기하에서 사라진다.

**방법.** 슬라이스 원 적합으로 축, 바깥 면 반지름 중앙값을 다듬어 프로필, 아래 25 mm와 스캔 최저 정점에 원호를 맞춰 둥근 바닥(1차의 원뿔 연장은 원본보다 뾰족했음), 벽 두께는 슬라이스별 바깥 20백분위 − 안쪽 80백분위(7.6 mm; 중앙값 차 11.5 mm는 과대), 구연부는 반원으로 마감. 스캔 삼각형을 (θ, z)로 펴서 래스터(z-버퍼 = 반지름), 색은 v1.6 텍스처, 요철은 반지름 잔차(±2.5 mm)를 노멀맵으로. 접합선(UV 경계)·균열(잔차 홈 ∧ 밝음 ∧ 길고 가늠)·구멍(깊고 넓음)은 저주파 보간 + 거울 복사한 결로 채운다. 파편 톤 차는 Lab 저주파(σ 25 mm) 평탄화로 없앤다.

**한계와 표기.** 회전체가 아닌 유물에는 못 쓴다. 결손부의 무늬는 이웃 결을 거울 복사한 추정이므로 VR 레이어에서 "복원 추정"으로 구분해야 한다(6절 기록 항목에 `method: idealized_revolution`, 커버리지, 검출 균열 수를 남김). 안쪽 벽의 균열·라벨은 아직 남는다.

### D. 참조 코퍼스 기반 기준색 — 프리셋을 "값"에서 "분포"로

- e뮤지엄 등 공개 사진 중 상태 양호 유물을 재질·시기별 N점 모아, 중성 회색 배경으로 노출·화이트밸런스를 정규화한 뒤 Lab 분포를 뽑는다. 프리셋이 평균 + 표준편차가 되어 **불확실도**를 같이 출력할 수 있고, "왜 이 색인가"에 대한 근거가 사진 N장으로 남는다(명세 FR-AI-007 출처 기록).
- 224의 배경 추정·전경 분리 코드가 그대로 쓰인다.

### E. 현재 ↔ 제작 당시 연속 전환 (부식 타임라인 재활용)

- PoC의 `timeline.py`(부식 타임라인)를 뒤집어, 두 텍스처 사이를 d(손상도)로 가중 블렌드하면 VR에서 슬라이더 하나로 "지금 → 제작 당시"를 보여줄 수 있다. 3단계 토글의 연장이고 비용이 거의 없다.

### F. 합성 부식으로 정답 만들기 — 검증의 기반

- 건전한 텍스처(참조 코퍼스 또는 복원 결과)에 절차적 부식(녹청 색 이동 + 노이즈 + 암점 + 박락 알파)을 입혀 (부식, 원본) 쌍을 만들면, 복원 품질을 ΔE로 정량 측정할 수 있다. 결손 복원에서 합성 파손을 쓰는 것과 같은 논리다. A의 학습 데이터로도 쓰인다.

**권장 조합.** 규칙 기반 v1(이 문서 1~7절)을 기준선으로 유지 → **A 세그멘테이션**으로 보호 마스크 교체 → **C PBR 금속**으로 재마감 확장 → D로 프리셋 근거 보강 → F로 정량 검증 → 시간이 남으면 B.

### F 착수 기록(9/13, 합성 부식으로 정답 만들기)

`synth_corrosion.py` + `eval_synth.py`. 같은 유물의 살아남은 건전 표면 절반에 부식을 합성해 입히고(나머지 절반은 복원의 기준으로 남긴다), 복원 후 원래 색과 직접 비교한다. 청자 don000498 ① 첫 결과: ΔE_ab 8.16 → 2.53, ΔE₀₀ 10.96 → 3.58. **복원이 색 오차의 69 %를 회복한다**는 첫 정량 증거. 남은 오차의 성격도 드러났다 — 대역 세기 비가 2.1~2.4(1.0이어야 함)로, 복원이 부식의 색은 지우지만 **결은 남긴다**. 밝기는 +2 L 과하다. 7절 완료 조건의 "합성 부식 복원 ΔE ≤ 4"는 ΔE₀₀ 3.58로 **충족**.

### F 후속(9/14, 정답이 지목한 세 가지를 고침 — v2.0)

정답 구간이 생기자 **무엇이 틀렸는지**를 처음으로 지목할 수 있게 됐다. 합성 부식 4건(청자 don000498 ①, 금동 bon009435, 백자 duk006294, 토기 ssu022891)이 공통으로 가리킨 세 가지를 고쳤다.

| 고친 것 | 정답이 보여준 증거 | 처치 |
| --- | --- | --- |
| ① 얼룩 게이트가 손상 **정도**에 비례 | 얼룩 면적의 57 %가 d < 0.2 구간에 있어 부식 결이 거의 그대로 남았다(대역 세기 비 1.8~2.4배) | 게이트를 "손상 여부"로 — `clip(d / DAMAGE_REPORT_D, 0, 1)`. `--stain-gate degree`로 옛 동작 재현 |
| ② 프리셋 비중 하나로 밝기·채도를 동시에 결정 | 최적 채도 비중은 0.00, 최적 밝기 비중은 0.30으로 서로 달랐다 | 분리 — 채도 `PRESET_BLEND = 0.10`, 밝기 `PRESET_BLEND_L = 0.30` |
| ③ 손상되지 않은 텍셀도 건드림 | 건전부 ΔE 1.21(금동). 7절 완료 조건은 ≤ 1 | 건전부 마스크 기준 통과(`--keep-healthy`, 기본 1.0) |

③은 한 번 틀렸다. 처음엔 **손상도**가 낮으면 통과시켰는데, 손상도가 곧 색 기준이라 "옅은 얼룩 = 저손상"이 되어 ①이 지우려던 것을 ③이 되살렸다(청자 ΔE_ab 2.25 → 3.40, 대역 비 2.10 → 3.77). 건전부 **마스크**를 기준으로 바꿔 해결했다. 색으로 정의한 값을 색 보존의 기준으로 쓰면 순환이 된다 — 8-F가 처음 드러낸 순환("손상부 ΔE(프리셋까지)")과 같은 함정이다.

합성 부식 4건 결과(기존 → v2.0):

| 유물 | ΔE_ab | ΔE₀₀ | 건전부 ΔE |
| --- | --- | --- | --- |
| 청자 don000498 ① | 2.25 → **2.19** | 2.96 → **2.89** | 0.52 → **0.41** |
| 금동 bon009435 | 4.87 → **3.46** | 5.49 → **5.31** | 1.21 → **0.87** |
| 백자 duk006294 | 2.77 → 3.01 | 3.02 → 3.19 | 0.58 → **0.49** |
| 토기 ssu022891 | 7.55 → **7.46** | 6.01 → **5.77** | 4.34 → **4.25** |

11건 전체 회귀에서 건전부 교란(`healthy_dE_mean`)이 전 유물에서 크게 줄었다: 금동 duk003312 10.13 → 2.99, 청자 gae000001 ② 11.75 → 0.21, 토기 8.39 → 0.89. L-SSIM은 6건 상승, 5건은 0.002 이내 하락(측정 잡음 수준).

**밝기 비중은 한 상수로 맞출 수 없다.** 0.30 → 0.45로 올리면 청자 ΔL −0.90 → +0.02, 금동 −2.97 → −2.49로 좋아지지만 백자는 −2.74 → −3.44로 나빠진다. 프리셋의 기준 밝기가 유물마다 맞거나 틀리기 때문이고, 이는 8-D(참조 코퍼스, 프리셋을 "값"에서 "분포"로)가 필요한 이유의 정량적 근거다. 기본값은 0.30으로 뒀다.

**정답이 못 재는 두 가지**도 분명해졌다. ⑴ 토기는 복원본(ΔE_ab 7.46)이 부식된 입력(5.45)보다 오히려 나쁘다 — 건전부가 4.9 %뿐이라 기준이 프리셋 쪽으로 끌려간다. ⑵ 청동 lkh000002는 건전부가 0.0 %라 합성 부식 자체가 불가능하다. 둘 다 "유물 안에 근거가 없다"는 같은 문제이고, 답은 8-D다.

### G. 파편 안쪽 균열 자동 검출 — 9/10 시도와 보류

메시 요철(스무딩 사본까지의 부호 있는 거리)에는 균열이 또렷하다. 그러나 빗살무늬토기에서 균열과 **깊은 장식 홈**을 규칙으로 갈라내지 못했다: 밝기(석고)·폭(빗살 1 mm vs 균열 2~4 mm)·주변 홈 밀도 셋 다 분포가 겹친다(2b절 표). 남은 길은 ① 균열 전용 학습 모델(콘크리트 균열 세그멘테이션의 전이학습), ② 뷰어에서 붓으로 칠하는 반자동(8-A의 연장), ③ 회전체 유물은 이상화 회전체(C′)로 우회. 현재는 ②·③을 쓰고 자동 검출은 `--geom-cracks` 옵션으로만 남겼다.
