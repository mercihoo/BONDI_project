# ai/3d-to-3d-color — 3D 출력의 색·질감 후처리

2D→3D 생성 모델이 만든 GLB를 **입력 사진의 색에 맞추고**(`color_match.py`), **메시를 바꾸지 않고 요철을 더하는**(`relief_maps.py`) 단계다.

```text
2D 사진 → ① 3D(파손) → [색 맞춤 color_match.py] → [요철 relief_maps.py] → ② 3D(복원) → ③ 제작 당시 색
```

주요 범위: 색 맞춤, 높이맵·노멀맵 생성, 금속 재질 검증.

## 환경

`C:\ai\venv-3dtools` (Python 3.11: numpy, scipy, trimesh, pillow, scikit-image, matplotlib, rembg, onnxruntime). 없으면:

```bash
uv venv C:\ai\venv-3dtools --python 3.11
uv pip install --python C:\ai\venv-3dtools\Scripts\python.exe numpy scipy trimesh pillow scikit-image matplotlib rembg onnxruntime
```

첫 실행 때 배경 제거 모델(u2net, 약 176 MB)을 내려받는다. 세션 임시 폴더에 환경을 두지 않는다(삭제됨).

## 1. 색 맞춤 — `color_match.py`

사진의 유물 픽셀(rembg 배경 제거 + 배경색 근접 픽셀 제거)과 모델 표면이 실제로 쓰는 텍셀(면적 가중 샘플링)의 색 분포를 CIE Lab에서 맞춘다. base color 텍스처만 바꾸고 메시·UV·다른 텍스처는 그대로다.

```bash
C:\ai\venv-3dtools\Scripts\python.exe color_match.py --photo <사진.jpg> --model <모델.glb> --out <출력폴더> --method <방식>
```

| `--method` | 하는 일 | 재질 |
| --- | --- | --- |
| `reinhard` (기본) | L·a·b 평균과 표준편차 일치 | 무광 토기 |
| `hist` | 채널별 분위수 일치 (더 강함) | 무광, 분포까지 따라야 할 때 |
| `chroma` | a·b 전체 일치, L은 평균만 이동 | 텍스처 고유 명암을 지킬 때 |
| `hue` | a·b **평균만** 이동, L 유지 | **금속·유광**. 금속의 base color는 반사율이라 사진 밝기를 복사하면 안 됨 |

옵션: `--strength 0~1`(원본과 섞기), `--erode N`(마스크 침식 px, 기본 6), `--bg-reject dE`(배경색 근접 픽셀 제거, 기본 12, 0이면 끔), `--tag`.

출력: `<모델>_colormatched_<방식>.glb`, 전후 텍스처 PNG, `color_match_compare_<방식>.png`(사진 | 전 4방향 | 후 4방향), `color_match_hist_<방식>.png`(Lab 분포), `color_match_<방식>.json`(파라미터·통계·ΔE, FR-AI-005 기록).

조건과 한계: UV 텍스처가 있는 GLB만 지원(정점색 OBJ 미지원). 전역 분포 변환이라 사진의 특정 얼룩을 특정 위치로 옮기지 않는다. 사진의 조명·화이트밸런스가 그대로 목표가 된다. 재질이 여러 개면 각각을 사진 전체 분포에 맞춘다.

## 2. 높이맵·노멀맵 — `relief_maps.py`

색 텍스처 밝기(Lab L)의 1~16 px 대역을 "주변보다 어두우면 낮다"로 높이맵(16bit, 마스터)으로 만들고, 기울기로 노멀맵(glTF/OpenGL 규약)을 파생해 GLB `normalTexture`에 넣는다. 메시가 실제로 쓰는 텍셀(UV 삼각형 래스터화) 안에서만 필터해 아틀라스 조각 경계의 가짜 능선을 막는다.

```bash
C:\ai\venv-3dtools\Scripts\python.exe relief_maps.py --model <색맞춤.glb> --out <출력폴더> [--sigma-small 1] [--sigma-large 16] [--slope-deg 25]
```

출력: `height_<tag>_16bit.png`(마스터), `height_<tag>.png`, `normal_<tag>.png`, `<모델>_normal.glb`, `relief_<tag>_preview.png`, `relief_<tag>.json`. 요철은 색에서 추정한 것이라 `ai_inferred`로 기록된다.

## 2b. 제작 당시 색 복원 v2.0 — `restore_original_colour.py`

보존처리 절차를 Lab 텍스처 처리로 옮긴 규칙 기반 파이프라인. 유효 텍셀 → 건전부 검출(상위 15 % 분위수, 로버스트 정규화) → 손상도 d → 보호 마스크 → **재마감**(손상부 색도를 목표색으로 이행하고 색 편차를 25 %로 압축, 명도 재정규화 `--tone`, 금속은 부식 얼룩 탈색 `--destain`) → 어두운 텍셀의 채도 sRGB 범위 보정 → Taubin 스무딩(정점 이동 상한 0.07 % 대각선) → 프리셋 PBR·부드러운 노멀을 넣은 GLB + JSON 기록.

v1.0~1.1은 "conserved = L 보존"으로 색도만 바꿨는데, 9/9 뷰어 검수에서 PoC(8/27)보다 못한 두 가지가 확인됐다: 백자는 색이 거의 안 바뀌어 보이고(PoC의 색도 이행 하한 0.85가 없었음), 금동은 부식 얼룩의 명암이 그대로 남았다. v1.2에서 PoC의 `chroma_strength`·`tone_strength`를 이식하고, v1.3에서 얼룩 제거(`--destain`)와 색 편차 압축을 넣어 해결했다. 기본값은 재질군별이다.

| 단계 | 도자기·토기 기본 | 금속 기본 | 뜻 |
| --- | --- | --- | --- |
| `--chroma` | 0.85 | 0.85 | 손상 텍셀의 a·b를 목표색으로 최소 이 비율만큼 옮긴다(위로는 손상도 d 가중). 편차는 `목표 + 0.25·(a − 평균)`으로 압축(PoC `refinish`) |
| `--tone` | 0.8 (PoC) | 0.3 | 보호 안 된 표면의 평균 L을 재질 L(0.38 건전부 + 0.62 프리셋)로, 대비는 gain ≤ 1로 압축(PoC `tone_strength`) |
| `--destain` | 0.7 (v1.5, 어두운 마모부를 주변 유약 밝기로) | 1.0, 창 1024 px (v1.4) | 부식 얼룩 제거. 1/8 해상도에서 L의 90 백분위 포락선(창 `--destain-size` 512 px)을 구해 손상 텍셀(d ≥ 0.5면 전부)을 그 높이로 올리고, 고주파 세부는 손상도에 따라 감쇠해 재부착. 전역 tone은 얼룩을 못 없애서 필요했다 |
| `--protect-dark` | `all` | `off` | 근흑색 보호. 금속의 어두운 부분은 장식이 아니라 부식이라 끈다(금동 좌상에서 34 %가 보호돼 얼룩으로 남았던 원인) |
| 채도 범위 보정 | 자동 | 자동 | 어두운 텍셀은 sRGB에서 채도를 못 담아 금색이 갈색 진흙이 된다 → `C ≤ 1.15·L`로 스케일 |
| 무늬 보존 (v1.4) | 자동 | 자동 | 구조 텐서 **일관성**(선처럼 방향이 있는 세부 = 무늬·선각, 점처럼 흩어진 세부 = 부식 구멍)으로 세부 재부착을 가중. 일관성이 높은 세부는 손상도와 무관하게 되붙이고, 낮은 세부만 손상도로 감쇠. 같은 성분으로 **무늬 노멀맵**(`normal_pattern_*.png`)을 만들어 GLB `normalTexture`에 넣어 색 텍스처를 평탄하게 만들어도 무늬가 요철로 보인다(`--no-normal-map`으로 끔). 금동 관모의 비늘 무늬가 v1.3에서 사라졌던 문제 |
| 색 편차 수렴 (v1.4·1.5) | 0.15·(1 − d) | 0.10·(1 − d) | 손상도가 높을수록 색 편차를 0으로 수렴. 청자 이빨·굽의 마모부가 25 %를 남겨 베이지로 남던 문제 |
| 마모/그림 분리 (v1.4) | 자동 | — | 메시 **곡률**을 텍셀로 래스터해 볼록한 상위 10 %(테두리·이빨·굽) 위의 갈색은 마모(복원), 평면의 갈색은 그림(보호). `mask_convex_*.png` |
| 파편 접합부 = UV 조각 경계 (v1.5) | `--remove-cracks` 시 | 같음 | 접합 스캔은 UV 조각이 곧 파편이라 **조각 경계가 접합선**이다. 텍스처 공간 인페인팅은 경계를 넘지 못해 v1.4에서 접합선이 남았다. 경계 정점(같은 위치에 UV가 둘 이상)을 양쪽 조각에서 샘플해 평균으로 맞추는 교차 조화(경계 16 px 페더 밴드), 경계 정점 홈 Taubin 스무딩, 노멀맵에서 경계 밴드 평탄화. `--no-uv-seams` |
| 대역별 변화 폭 상한 (v1.9) | 도자기, 건전부 ≥ 3 % | 같음 | 복원한 손상부가 **살아남은 건전 표면보다 얼룩덜룩하면** 안 된다. 결과와 건전부를 σ 3·12·48·192 px 대역으로 나눠 손상부의 대역 표준편차가 건전부를 넘으면 그 대역만 손상도만큼 줄인다. 평균과 가장 큰 대역(형상 음영)은 건드리지 않는다. 건전부가 3 % 미만이면 **건너뛴다**(부식된 표면은 기준이 될 수 없다). `--band-match`, `--band-cap` |
| 세부의 심판을 기하로 (v1.8) | 항상 | 같음 | 색 고주파를 되붙일 때 **메시에 그 요철이 실제로 있는지**를 본다. 메시 잔차(스무딩 사본까지의 거리)를 2K로 구워 3 mm 대역만 남기고 국소 에너지를 80백분위로 정규화한 것이 `support`. 손상 텍셀인데 support가 0이면 그 고주파는 도구 자국이 아니라 얼룩이므로 `keep`을 손상도만큼 깎는다. 건전 텍셀은 그대로 둔다. `--geom-detail`(0 = v1.7), `mask_geom_support_*.png` |
| 무늬 되살리기 (v1.7) | `--remove-cracks` 시 | 같음 | 메운 자리는 매끈해서 빗살이 끊긴다. 무늬가 실제로 사라진 자리(균열 채움 + 조각 경계 1.5 mm 고리)를 **핵**으로 잡고, 거기서 **3 mm까지 페더**되는 가중치로 고주파를 **교체**한다(더하지 않는다: 더했더니 띠의 고주파 표준편차가 4.2로 주변 2.7보다 커졌다). 교체할 값은 온전한 영역 가장자리 **바깥으로 대칭인 텍셀**(q = 2·최근접 − p)의 고주파다. 저주파는 지금 색(TELEA·경계 조화) 그대로 둔다. 반복 무늬라 결이 이어진다. 복사 원본은 **같은 UV 조각 안**으로 제한해 옆 파편 무늬가 붙지 않게 한다. 노멀맵은 이제 이 띠를 평탄화하지 않고 되살아난 무늬를 그대로 쓴다. `--fill-band`(0 = v1.6) |
| 무늬 재양각 (v1.7) | `--remove-cracks` 시 | 같음 | 색뿐 아니라 **기하**에도 무늬를 되돌린다. 메시를 강하게 스무딩한 사본까지의 부호 있는 거리(= 실제 요철)를 텍스처로 구운 뒤, 위와 같은 대칭 복사로 띠를 채우고, 홈 메우기로 평평해진 띠 정점을 그 값만큼 법선 방향으로 민다(상한 0.6 mm, 가장자리 페더). 조명·실루엣 어디서도 빗살이 이어진다. `--reemboss 0`으로 끔 |
| 접합선 홈 메우기 (v1.6) | `--remove-cracks` 시 | 같음 | 띠는 v1.7에서 2링 → **3링**(약 11 mm)으로 넓혔다. 9/10 측정: 토기 접합선은 텍스처보다 **메시의 홈**이 문제였다(접합선 이면각 12° vs 그 외 7.7°). v1.5의 경계 정점 한 줄 Taubin은 0.02 mm만 움직여 조명 아래 밝은 선이 그대로 남았다. 접합선·균열 마스크 정점 + 2링(약 7 mm 띠)을 풀어 놓고 나머지를 고정한 채 라플라시안 에너지 최소(쌍조화 곡면 = 구멍 메우기)로 다시 풀어 홈·턱을 없앤다. 이면각 12° → 2.8°, 이동 평균 0.8 mm, 최대 5 mm(상한 대각선 2 %). `--groove-rings`(0 = v1.5 Taubin) |
| 조각 경계 띠 밝기 (v1.6) | `--remove-cracks` 시 | 같음 | 파편 사진마다 테두리 띠가 안쪽보다 어둡다(바깥 8 px L 67.7 vs 안쪽 73.6). 교차 조화는 양쪽 **차이**만 없애서 둘 다 어두운 띠는 남았다. 테두리 24 px 띠의 저주파 색을 안쪽 텍셀의 국소 평균(정규화 컨볼루션, σ 12)으로 바꾸고 고주파(빗살)는 그대로 둔다. 노멀맵 평탄화 띠도 같은 폭. `--border-band`(0 = 끔) |
| 접합선 후보 (v1.5) | `--remove-cracks` 시 | 같음 | 텍스처 색 규칙은 폭이 넓고 대비가 약한 접합선을 놓친다(빗살무늬토기). 메시의 **오목 곡률**(홈)을 텍셀로 래스터해 상위 5 %를 후보에 합친다. 빗살 자국도 홈이지만 짧아서 균열 길이·두께 필터에서 떨어진다. `--no-mesh-seams`, `--mesh-seam-frac`. `mask_groove_*.png` |
| 균열 채움 (v1.4) | `--remove-cracks` 시 | 같음 | OpenCV TELEA 인페인팅(PoC 방식)으로 교체. 넓은 밝은 접합선을 위해 기준 블러 폭을 균열 두께에 맞춤. 균열 띠는 노멀맵·일관성 계산에서 제외(지운 선이 요철로 되살아나던 문제). 접합선 아래 정점만 Taubin 스무딩(`--no-crack-smooth`로 끔, 이동 상한 대각선 2 %) |
| 상감 보호 | — | 자동 | 금속 위의 옥·유리·칠보: 차가운 색상(hue 175~320° 또는 < 20°)이고 채도 > 12, L\* > 35인 군집을 보호. 녹청은 hue 130~180°·어둡고 탁해 걸리지 않는다. bon004740 터키석 상감(C ≈ 19, L ≈ 47, hue ≈ 190)이 v1.3에서 금색으로 덮여 추가 |

금속 프리셋 PBR은 `gold`·`gilt_bronze` metallic 1.0 / roughness **0.55**(9/9 뷰어에서 0.35는 거울처럼 번쩍여 PoC 출력값 0.55로 결정). GLB에는 이 값과 위치 기준으로 다시 계산한 부드러운 정점 노멀이 들어간다(스캔 OBJ는 면 노멀이 갈라져 있어 금속 재질에서 삼각형이 드러났다).

```bash
C:\ai\venv-3dtools\Scripts\python.exe restore_original_colour.py --model <복원.glb> --out <출력폴더> --material bronze --mode both
```

| 옵션 | 값 |
| --- | --- |
| `--material` | `gold` `gilt_bronze` `bronze` `iron` `silver` `celadon` `whiteware` `earthenware`(적갈색 토기, PoC) `stoneware`(회청색 경질토기, 추가) |
| `--mode` | `conserved`(기본) / `pristine`(손상부 밝기 분포를 건전부 분포로 통째로 매핑, "새것") / `both`. pristine은 건전부가 3 % 미만이면 기준 분포가 없어 **만들지 않는다**(부식 금속에서 평평한 겨자색이 나오던 문제) |
| `--target` | `auto`(기본): 건전부가 3 % 이상이고 그 색이 프리셋과 타당성 임계(금·금동 25, 나머지 15) 안이면 건전부·프리셋 혼합, 아니면 프리셋 / `healthy` / `preset` |

## 2b-1. 합성 부식으로 정답 만들기 — `synth_corrosion.py` · `eval_synth.py` (설계 8절 F, 7절)

지금까지 쓰던 "손상부 ΔE(목표색까지)"는 **평평할수록 좋아지는** 지표라, 결을 살리는 변경은 반드시 나빠 보였다. 정답이 있어야 판정이 된다. 같은 유물의 **살아남은 건전 표면** 일부에 부식을 합성해 입히고(원래 색을 아니까 그게 정답), 복원한 뒤 가려 두었던 색과 직접 비교한다. 건전부를 다 덮으면 복원이 기준을 잃으므로 절반만 덮는다.

```bash
python synth_corrosion.py --key don000498_001 --material celadon --severity 8 --cover 0.45
python restore_original_colour.py --model C:/ai/poc_synth/don000498_001/don000498_001_30000.obj --out out_restore/synth_don000498_001_v19 --material celadon --mode conserved --no-smooth
python eval_synth.py --key don000498_001 --material celadon --restored out_restore/synth_don000498_001_v17 --restored out_restore/synth_don000498_001_v19
```

부식 모델은 그 유물 **자신의 실제 손상 통계**에 맞춘다(실제 손상부에서 잰 ΔL과 파티나 ab를 목표로). 세 크기(σ 120·40·12 px)의 얼룩장으로 어둡게 하고, 그 아래 세부를 뭉개고(60 %), 미세 반점을 더한다. 단일 크기 얼룩은 탈색 단계가 한 크기에서 동작하므로 너무 쉽게 지워져 시험이 되지 않는다.

**정답으로 고친 세 가지(9/14, v2.0).** 합성 부식 정답을 4건(청자·금동·백자·토기)으로 넓히고, 정답이 가리킨 결함 셋을 고쳤다.

### 3a. 마스크 붓 — 모델 위에 직접 칠하기 (설계 8절 A, 2단계)

균열·접합선 자동 검출이 장식과 갈라지지 않으므로(2b절), 사람이 모델을 보면서 칠하는 길을 뷰어에 넣었다. **칠하기**를 켜면 좌드래그가 붓, 우드래그가 회전이 된다. 칠한 자국은 화면이 아니라 **유물 텍스처 좌표**(4096², 클릭 지점의 UV)에 기록되므로, 저장하면 그대로 복원 스크립트의 마스크가 된다.

| 조작 | 내용 |
| --- | --- |
| 칠하기 / 지우개 / 붓 4~120 px | 붓 자국은 빨간 반투명 오버레이(같은 지오메트리에 겹친 두 번째 재질)로 즉시 보인다 |
| 되돌리기 / 전체 지우기 | 획을 목록으로 갖고 있다가 다시 그린다(4096² 스냅샷을 쌓지 않는다) |
| 저장 | `POST /api/mask/save` → `out_restore/mask_paint/<유물키>_paint.png`(흑백). 저장 후 상태줄에 그대로 쓸 명령이 뜬다 |
| 불러오기 | `GET /api/mask/load` → 이전에 칠한 것을 다시 올려 이어서 작업 |
| 이 마스크로 복원 | `POST /api/restore` → 서버가 지금 화면 변형의 옵션(암부 보호·톤·채도·탈색과 **균열 검출 파라미터**)을 그대로 넘겨 `restore_original_colour.py`와 `make_viewer_copies.py`를 돌리고, 끝나면 뷰어가 새 변형(`*_brush`)을 자동으로 띄운다. 칠한 마스크는 **화면 변형이 쓰던 마스크와 합쳐**(`<키>_combined.png`) 넘긴다. 8K 한 건 12~15분, 경과 시간과 로그가 상태줄에 뜬다 |

구현에서 걸린 것 넷: ⓪ 처음에는 재실행이 **화면보다 나쁜 결과**를 냈다. 이전 SAM·손 마스크를 빼고 새로 칠한 것만 쓰고, 균열 검출 파라미터도 기본값으로 돌렸기 때문이다(균열 성분 104 → 18개, 채움 2.36 % → 0.37 %). 그래서 마스크를 합치고 파라미터를 JSON(`crack_params`)에 기록해 그대로 되넘긴다. ⓪′ 자식 프로세스의 출력이 파이프에서 블록 버퍼링돼 10분 넘게 로그가 비어 멈춘 것처럼 보였다(`PYTHONUNBUFFERED`).  ① 파편 경계를 넘어 드래그하면 아틀라스에서는 먼 두 지점이라 **직선이 엉뚱한 조각을 가로지른다** → 붓 반지름의 4배(최소 48 px)를 넘는 UV 도약이면 획을 끊는다. ② 이상화 회전체·8/27 PoC 변형은 UV 배치가 달라 칠할 수 없다(경고를 띄우고 막는다). 규칙 기반 복원본 위에서 칠할 것.

버튼을 쓰지 않고 직접 돌릴 때(다른 옵션을 주고 싶을 때):

```bash
python restore_original_colour.py --model <obj> --out <dir> --material earthenware \
    --remove-cracks --crack-mask out_restore/mask_paint/ssu022891_paint.png     # v1.7이 이 자리를 메우고 무늬를 되살린다
```
