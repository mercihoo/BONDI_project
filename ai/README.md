# ai — AI 파이프라인

2D→3D 생성, Blender MCP 복원, 후처리를 담당한다.
담당 직군: **AI**

## 여기에 넣는 것

- 2D→3D 생성 파이프라인 (TripoSR / Hunyuan3D 래퍼)
- Blender MCP 복원 작업 스크립트와 프롬프트
- 메시 경량화·재질 정리 스크립트
- 품질 평가 스크립트
- `pyproject.toml`, `uv.lock` 등 환경 고정 파일

## 여기에 넣지 않는 것

| 대상 | 어디로 |
| --- | --- |
| 생성된 유물 자산 | `assets/<artifact-id>/` |
