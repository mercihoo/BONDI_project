# 복원 구현 단계

손상된 유물 3D 스캔을 **원본 + 복원 추가분** 형태로 만드는 전체 절차.
LaS-Comp(CVPR 2026) 제로샷 3D 완성을 8GB GPU 에서 돌리고, 결과를 원본 위에 얹어 실측 외관을 남긴다.

대상: 굽다리바리 (손상 스캔 · 정점 154,971 · 면 248,938 · 2048² 사진 텍스처)
환경: RTX 4070 Laptop 8GB (WSL2 Ubuntu 22.04 · conda `lascomp`)

```
0 준비 → 1 조건 → 2 희소 구조(64³) → 3 SLat·메시 → 4 원본에 얹기 → 5 질감 → 6 UV 굽기 → 7 평가 → 8 등록
                                                                      └ (선택) 높이로 갈라 합치기
```

---

## 0단계 — 준비

### 0-1. 유물 자료 내려받기

`artifacts/<이름>/source_model.glb` + `photo_01.jpg`. 자료 서버(`/api/cards`)에서 원본 3D 를 받는다.

### 0-2. 점군 만들기 — `tools/prep_artifact.py`

원본 GLB 표면에서 **10만 점**을 균일 표본으로 뽑아 `partial.ply` 로 저장한다.
모델 입력은 점군이다 — 메시를 그대로 넣지 않는다.

| 산출 | 내용 |
| --- | --- |
| `partial.ply` | 원좌표 · Y-up · 반폭 0.501 · 100,000 점 |

### 0-3. 좌표계 진단 — `tools/inspect_glb.py`

축 방향(Y-up / Z-up)과 반폭을 재서 실행 인자를 정해 준다.
굽다리바리는 `--dataset custom --yz-flip --normalize-partial`.

> **왜 필요한가.** LaS-Comp 은 내부에서 y/z 를 교환한다. 여기서 축을 잘못 주면 결과가
> 90° 누운 채로 나오고, 4단계의 거리 비교가 전부 틀어진다.

## 1단계 — 조건 만들기

### 1-1. 가이드 이미지 고르기 ★ 가장 중요한 선택

모델은 **조건 이미지가 보여 주는 형상을 따라간다.**

| 넣은 것 | 결과 |
| --- | --- |
| 이 유물의 **손상된** 소장품 사진 | 깨진 모습을 그대로 재현 — 복원이 거의 안 된다 |
| 다른 유물의 온전한 사진 | 형태가 그 유물 쪽으로 끌려간다 |
| **이 유물의 온전한 형상 렌더** | 몸통이 닫힌다 ← 채택 |

> 가이드 이미지 네 장을 갈아 가며 시험해 확인했다. 조건 이미지는 **복원하려는 그 유물의 온전한 모습**이어야 한다.

### 1-2. 모델이 실제로 보는 것

DINOv2 는 입력을 **518×518** 로 리사이즈한다. 원본 해상도가 클수록 리사이즈 손실이 적다.
(guide7 610×666 → guide8 1015×1129 로 올렸을 때 채움량이 56.9% → 70.9% 로 늘었다.)

## 2단계 — 희소 구조 (64³ 격자)

"어디가 물체인가"만 정하는 단계. 형태의 큰 틀이 여기서 결정된다.

### 2-1. 흐름 샘플링 100 스텝

TRELLIS 의 `sparse_structure_flow_model` (Linear 196개) 이 조건 이미지를 보고 64³ 점유를 만든다.

### 2-2. ERS — Explicit Replacement Stage

매 스텝마다 **관측된 복셀을 1 로 고정**한다. `trellis/pipelines/samplers/flow_euler.py`:

```python
pred_voxel = (decoder(x_0) > 0.0).float()
pred_voxel[voxel_mask] = 1.0          # 관측 복셀 → 1
x_0_new = encoder(pred_voxel, sample_posterior=False)
```

> **한쪽 방향뿐이다.** "관측된 표면은 지켜라"는 있지만 **"여기는 비어 있어야 한다"는 장치가 없다.**
> 그래서 굽다리 투창(뚫린 창)처럼 *없어야 하는* 구조는 어떤 파라미터로도 지킬 수 없다 → 7-2 참고.

실측 로그: 스텝당 복셀 수가 32,411 → 32,955 로 **늘어난다**(약 +540). 줄어드는 경우는 없다.

### 2-3. IAS — Implicit Alignment Stage

잠재 변수에 Adam(lr 1e-5)을 걸고, 관측 복셀에 대한 BCE 손실로 정렬한다.
`--optimization-step 1` 이 기본. 0 이면 끄고, 2 이상은 미시도.

> IAS 를 켜면 `_get_model_prediction` 이 스텝당 3회 호출된다 — 다중 이미지 조건 훅을 만들 때
> 저자 코드의 `cond_indices` 리스트가 소진되는 원인이 이것이었다(순환 카운터로 교체).

**산출**: `sparse_structure.ply` (차지한 칸 = 굽다리바리 46,811 ~ 51,678 개)

## 3단계 — SLat → 메시

### 3-1. SLat 흐름 샘플링

`slat_flow_model` (Linear 203개) 이 64³ 점유 위에 구조화 잠재(Structured Latent)를 채운다.

### 3-2. 디코딩 → FlexiCubes 표면 추출

`slat_decoder_mesh` 가 SLat 을 SDF·변형장으로 풀고, FlexiCubes 가 res 256 에서 표면을 뽑는다.

> **여기가 메모리 최대 지점**이었다 (7350 MiB · OOM). 디코더 업샘플 2단계의 `SparseGroupNorm32` 가
> fp32 사본을 약 8배 만들어서였다 — 조각 정규화 훅으로 3276 MiB 로 내렸다. 양자화 문서 참고.

### 3-3. 모델 예측 색 건져 오기

저자 저장 코드는 `MeshExtractResult.vertex_attrs` (6채널 = 색 3 + 법선 3) 를 **버린다.**
`LASCOMP_COLOR_OUT` 훅으로 가로채 `output_mesh_colors.npz` 로 남기고 `apply_colors.py` 가 GLB 에 입힌다.

> 다만 이 색은 쓸 수 없었다 — 조건 이미지가 회색 무광 렌더라 **예측 색의 1~99 백분위가
> 0.091~0.332**, 사실상 무채색 한 톤이다. 그래서 5단계에서 원본 실측 텍스처로 대체한다.

**산출**: `output_mesh.glb` (약 110만 면) · `output_mesh_color.glb` · `output_mesh_colors.npz`

## 4단계 — 원본에 복원 추가분 얹기 — `tools/composite.py`

> **왜 반드시 필요한가.** LaS-Comp/TRELLIS 는 표면을 **통째로 다시 생성**한다 — 원본에 덧붙이는
> 구조가 아니다. 모델 출력만 보이면 원본 실측이 하나도 남지 않는다. 그래서 합치는 단계를
> 사람 손이 아니라 **파이프라인 고정 단계**로 둔다 (`postprocess.sh`, `ADD=0` 으로만 끈다).

### 4-1. 프레임 자동 선택

결과는 LaS 내부 프레임(y/z 교환·거울)이다. 후보 5개를 원본 표면까지의 중앙값 거리로 재서 고른다.

```
same 0.09293 · swap_yz 0.00743 ← 채택 · swap_yz_negz 0.01707 · swap_yz_negy 0.12392 · swap_yz_negyz 0.10413
```

거울 프레임이면 면 감김을 뒤집어 법선을 지킨다.

### 4-2. 결손 판정 — 거리 문턱 τ

원본 표면을 200만 점으로 조밀 표본하고, LaS 메시의 **면 중심**에서 그 표면까지의 거리를 잰다.
**τ 보다 먼 면만** 채움으로 채택한다 (= 원본에 없는 곳).

### 4-3. 섬 제거

채택된 면을 연결 요소로 쪼개고, **전체 면적의 일정 비율보다 작은 조각을 버린다.**
관측부를 다시 그린 잔재가 작은 부스러기로 남기 때문이다.

### 4-4. 2노드 GLB 로 저장

```
restored_with_original.glb
├─ geometry_0          원본 스캔 그대로 (정점·면·사진 텍스처 불변)
└─ lascomp_gap_fill    τ 밖 채움 면만
```

원본 노드는 **한 정점도 건드리지 않는다.**

## 5단계 — 채움부에 실측 질감 — `tools/texture_fill.py`

물레로 돌린 그릇은 **같은 높이대의 표면 통계가 회전 방향으로 같다.** 이 성질을 쓴다.

### 5-1. 원본 텍스처 → 정점 색

원본의 2048² 사진 텍스처를 UV 로 표본해 정점 RGBA 154,971개로 만든다
(`visual.to_color()`). 이후 계산은 전부 이 배열 안에서만 일어난다 — **새 색을 만들지 않는다.**

### 5-2. 회전축 잡기 — 최소제곱 원 맞추기

깨진 몸통의 무게중심은 치우치므로, **온전한 굽다리 바닥 고리**(높이 하위 8%, 정점 15,159개)에
원을 맞춘다.

```
(x−a)² + (z−b)² = R²  →  2ax + 2bz + c = x²+z²      (a, b, c 에 대해 선형)
```

굽다리바리: 중심 (−0.0206, 0.0589) · 반지름 0.3206

### 5-3. 원통 좌표로 펼치기

정점을 `(높이 h, 각 θ)` 로 옮긴다. 각에 평균 반지름을 곱해 높이와 단위를 맞추고,
θ 는 순환이므로 ±2π 사본을 붙여 KD-트리가 −π/+π 경계를 넘어 찾게 한다.

### 5-4. 거울 반사로 실측 표면 끌어오기

```
높이 h 에서 위에서 본 단면

   실측 표면 ━━━━━━━━━━━━━━━●θ_b ┈┈┈┈┈┈ 결손 ┈┈┈┈┈┈
                       ↑              ↑
                    θ_src            θ  ← 색을 채울 정점
                  = 2θ_b − θ
```

① 같은 높이대의 최근접 실측 표면 = 파단면 경계 θ_b
② 그 경계를 거울로 삼아 `θ_src = 2θ_b − θ` 로 되짚어 인접 실측 표면을 결손부로 반사

경계에서 반사량이 0 이라 **이음선이 없고**, 같은 높이대라 **물레 흔적(가로 띠)이 이어진다.**

실측: 채움 정점의 **88.5%가 반사로 채워지고**, 표본까지의 거리 중앙값이 0.0052 → **0.0018** (약 3배 감소).

### 5-5. 방식 세 가지

| 방식 | 하는 일 |
| --- | --- |
| `mirror` | 고른 실측 색을 그대로 복사. 좁은 결손은 최상, 넓은 결손은 **흙얼룩까지 복사**된다 |
| `band` | 높이만 쓴다 — 높이 200칸의 색 중앙값 → 이동평균 → 보간. 얼룩 없음, 매끈함 |
| **`blend`** ← 채택 | 톤은 높이대에서, **결만** 실측 고주파에서. `이웃 k 평균과의 차`를 얹는다 |

```python
smoothed = rgb_obs[nb].mean(axis=1)      # 원본을 이웃 k 개로 국소 평균 → 얼룩·톤이 여기 남는다
detail   = rgb_obs - smoothed            # 남은 것 = 태토 결·물레 흔적
mix      = band_tone(fh) + gain * detail[pick]
```

k·세기 값은 [사용모델 + 파라미터설명.md](사용모델%20+%20파라미터설명.md) 참고.

**기하는 건드리지 않는다** — 정점·면 그대로, 정점 색만 채운다.

## 6단계 — UV 텍스처로 굽기 — `tools/bake_fill_texture.py`

### 6-1. 왜 필요한가

자료 서버는 올린 GLB 를 Blender 로 **경량 미리보기로 다시 만든다.** 그때 원본(텍스처)과
채움(정점 색)을 한 오브젝트로 합치면서 **텍스처 메시용 흰색 더미 색 속성이 `COLOR_0` 을 차지하고
실제 채움 색이 `COLOR_1` 로 밀린다.** three.js 는 `COLOR_0` 만 읽으므로 화면에서 단색으로 보인다.

실측 (2026-09-17):

```
prim[0] (원본, 텍스처)   COLOR_0 = 255,255,255 전부 흰색   COLOR_1 = 0,0,0
prim[1] (채움)           COLOR_0 = 255,255,255 전부 흰색   COLOR_1 = [151, 144, 133] ← 실제 질감
```

정점 색을 없애면 이 경로가 사라진다. 덤으로 텍셀 밀도가 원본과 같아진다
(정점 색 34만 개 ≈ 원본 2048² 의 1/7 → 2048² 로 동등).

### 6-2. 원통 펼치기

```
u = (θ + π) / 2π      v = (h − h0) / (h1 − h0)
```

### 6-3. 이음선 처리

u 범위가 0.5 를 넘는 면(±π 를 가로지르는 면)은 작은 u 쪽 꼭짓점을 복제해 `u+1` 로 둔다.
텍스처가 u 방향으로 주기적이고 glTF 기본 래핑이 REPEAT 이라 같은 열을 다시 읽어 이음선이 없다.

실측: 이음선 면 1,321개 · 복제한 꼭짓점 675개 (전체 34만 정점 중 0.2%)

### 6-4. 텍셀 채우기

2048² 텍셀마다 그 `(u, v)` 의 최근접 채움 정점 색을 넣는다. UV 가 `(θ, h)` 의 함수이고
텍스처도 같은 좌표로 만들었으니 대응이 **정의상 정확하다.**

> **한계**: 굽다리 바닥처럼 수평인 면은 같은 높이가 한 v 줄에 몰려 늘어난다 (면적이 작고 대개 가려진다).

## 7단계 — 평가·렌더

### 7-1. Q4 관측부 보존 — `tools/eval_completion.py`

복원 결과가 원본 실측면을 얼마나 밀어냈는지. 중앙값·p95·복셀 1칸 밖 비율.

> **함정**: 이 지표만 보면 **아무것도 안 한 모델이 1등**이 된다. 실제로 "보존 최고"라고 보고한
> 실행의 렌더를 보니 테두리가 찢어져 있었다 — 채움이 거의 없어서 나온 점수였다.
> **판정 순서를 몸통 폐합(눈) → 채움량 → Q4 로 고정한다.**

### 7-2. 투창 측정

굽다리 벽을 `(높이 26칸 × 각 72칸 = 1,872칸)` 으로 펼쳐 **빈 구멍의 개수·크기**를 센다.
위·아래 테두리에 닿는 빈 덩어리는 결손이므로 창으로 세지 않는다.

```
                 채운 칸        남은 창
guide7          93.8%          2 개 (20칸, 7칸)
guide8         100.0%          0 개   ← 투창이 메워졌다
```

> **막힌 지점은 2단계다.** 1단계 복셀에서는 오히려 guide8 이 창을 더 남겼다(6개 vs 2개).
> 문제는 벽 두께였다 — 굽다리 구간 복셀이 4,315 → **5,773개(+34%)**. 투창은 64³ 에서
> **폭 2~3칸**뿐이라, 벽이 조금 두꺼워지면 FlexiCubes 가 양쪽 벽을 이어 버린다.
> τ·섬 임계는 완성된 메시의 후처리라 **되살릴 수 없다.**

### 7-3. 오프스크린 렌더 — `tools/render_mesh_views.py`

pyrender 로 4방향(정면·측면·후면·위) 메시 음영 렌더. `--views` 로 방향을 줄일 수 있다.

> **WSL 함정**: GPU EGL(mesa d3d12 "D3D12 (Intel Arc)")이 오프스크린 색 버퍼를 **전부 0** 으로
> 돌려줘 렌더가 검게 나왔다. `LIBGL_ALWAYS_SOFTWARE=1 GALLIUM_DRIVER=llvmpipe` 로 강제한다.
>
> **또 한 가지**: 데시메이션(250k 면 상한)이 정점 색을 버려서, 최근접 이웃으로 색을 옮겨 준다.

## 8단계 — 자료 서버 등록

```bash
# 원본
curl -X POST "$B/api/artifacts" -F "name_ko=굽다리바리4" -F "files_3d=@model.glb;type=model/gltf-binary"
# 복원본 (원본에 연결)
curl -X POST "$B/api/artifacts/<id>/restored" -F "method=..." -F "files=@model_restored.glb"
```

`restore_types` 는 `method` 글의 낱말로 자동 분류된다 — `결손`·`채움` → 형태, `질감` → 색,
`이미지`·`lascomp`·`trellis` → 2D→3D.

## 선택 단계 — 높이로 갈라 합치기 — `tools/hybrid_fill.py`

**채움이 많을수록 좋은 게 아니다.** guide8 은 테두리를 더 잘 닫았지만 굽다리 투창까지 메웠다.
두 실행의 채움을 높이로 갈라 잇는다 — 위(몸통·테두리)는 A, 아래(굽다리)는 B.

경계는 `composite.junction_fraction` — 세로축 둘레 반지름이 가장 좁아지는 높이(몸통·굽다리 목).

실측: 경계 = bbox 높이의 **0.383**. 위는 guide8 채움의 60.6%(513,619면), 아래는 guide7 채움의
35.6%(239,529면) → 합친 채움 753,148면 = 원본 면적의 63.2%.
투창 측정이 guide7 과 **완전히 같다** (93.8% · 창 2개).

기하는 만들지 않는다 — 면을 높이로 고르고 이어 붙이기만 한다.
