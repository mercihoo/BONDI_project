# 1부 — 사용 모델

## 1. 전체 구성

```
조건 이미지 ──▶ DINOv2 ViT-L/14-reg ──┐
                                      ├──▶ TRELLIS SS flow ──▶ 64³ 점유 ──▶ TRELLIS SLat flow ──▶ 디코더 ──▶ 메시
원본 점군 ────▶ (ERS·IAS 로 개입) ────┘                                                    (FlexiCubes res 256)
```

**LaS-Comp 은 새 가중치를 들고 오지 않는다.** 모든 가중치는 TRELLIS 것이고, LaS-Comp 이 더하는 것은
**샘플링 절차(ERS·IAS)뿐**이다 — 학습 없는 제로샷이다. 그래서 "우리 유물로 학습시켰다"가 아니라
"사전학습 생성 모델에 관측을 강제로 끼워 넣어 완성시켰다"가 정확한 설명이다.

## 2. 모델별 내역

| 역할 | 모델 | 규모·특성 |
| --- | --- | --- |
| 이미지 조건 인코더 | **DINOv2 ViT-L/14-reg** | `cond_channels = 1024` · 입력 518×518 |
| 텍스트 조건 인코더 | **CLIP ViT-L/14** | `cond_channels = 768` |
| 희소 구조 생성 | **TRELLIS `sparse_structure_flow_model`** | Linear 196개 · fp16 1,062.3 MiB |
| 구조화 잠재 생성 | **TRELLIS `slat_flow_model`** | Linear 203개 · fp16 1,147.9 MiB |
| 표면 디코딩 | **TRELLIS `slat_decoder_mesh`** + FlexiCubes | res 256 |
| 완성 절차 | **LaS-Comp** (ERS + IAS) | 가중치 없음 — 샘플러만 |

체크포인트: `ckpt/image-large` (채택) · `ckpt/text-xlarge` (텍스트 실험용)

## 3. 이미지 조건과 텍스트 조건은 같이 못 쓴다

조건 채널 수가 다르다 — **DINOv2 1024 vs CLIP 768.** DiT 의 cross-attention 입력 차원이
체크포인트에 박혀 있어서, 한 실행에 이미지와 텍스트를 함께 넣을 수 없다.
"이미지로 형태를 잡고 텍스트로 설명을 보태기"는 **구조적으로 불가능**하다.
둘 중 하나를 고르는 것이고, 형상 복원에는 이미지 조건이 확실히 낫다.

| 조건 | 결과 |
| --- | --- |
| 이미지 (가이드 렌더) | 몸통이 닫힌다 — 채택 |
| 텍스트 (프롬프트) | 형태가 일반적인 그릇으로 흐른다. XL DiT 는 fp8 에서 NaN (양자화 문서 §4-5) |

## 4. 다중 이미지 조건

이미지 파이프라인에 `inject_sampler_multi_image` / `run_multi_image` 가 있지만 **LaS-Comp 은 쓰지 않는다.**
`tools/quantize_trellis.py` 의 `install_multi_image_hook` (`LASCOMP_GUIDE_IMAGES`) 으로 붙여 두었다.

> 저자 코드의 popping `cond_indices` 리스트는 IAS 를 켜면 소진된다 —
> `sample_lascomp` 이 스텝당 `_get_model_prediction` 을 3회 부르기 때문이다. **순환 카운터**로 교체했다.

## 6. 거리 문턱 τ

### 뜻

복원 결과의 **면 중심**에서 원본 표면(200만 점 조밀 표본)까지의 거리를 재서,
**τ 보다 먼 면만** "원본에 없던 곳"으로 보고 채움에 넣는다.

### 단위 — 왜 복셀인가

```
τ_절대 = τ_복셀 × (1/64) × 물체 최대 변
```

모델의 1단계 격자가 64³ 이라 **복셀 1칸이 자연스러운 자**이다.
복셀 단위로 두면 유물 크기가 달라져도 같은 값을 쓸 수 있다 — **절대값을 고정하지 말 것.**

굽다리바리 기준: 복셀 1칸 = 0.01567 → **τ 0.6 복셀 = 0.0094**

### 범위와 효과

| τ | 효과 |
| --- | --- |
| 작다 (0.25) | 채움이 많아지고, 관측부를 다시 그린 면이 원본 위를 **덮는다** |
| 크다 (1.5+) | 원본 파단면이 또렷해지지만 이음새에 **틈**이 생긴다 |

측정된 맞바꿈 (`tools/tune_tau.py`, 굽다리바리) — 겹침 = 채움 면 중 원본에서 1복셀 안에 있는 비율:

```
τ 0.25 → 겹침 34%     τ 0.5 → 24%     τ 0.75 → 12%     τ 1.0 이상 → 0%
```

**추천 0.5 ~ 0.75.** 1.5 → 1.0 → 0.5 → 0.75 를 눈으로 비교한 뒤 0.65 로 정착했고,
지금은 0.6 을 쓴다.

## 7. 섬 제거 임계

### 뜻

τ 밖으로 판정된 면을 **연결 요소로 쪼개고, 전체 면적의 이 비율보다 작은 조각을 버린다.**

### 왜 필요한가

모델은 관측된 부분도 **다시 그린다.** 그 결과가 원본과 미세하게 어긋나면 τ 밖으로 밀려나
**작은 부스러기**로 남는다. 진짜 채움은 큰 덩어리 1~9개이고(면적의 90% 이상), 나머지는 0.5% 미만이다.

### 범위와 효과

| 임계 | 효과 |
| --- | --- |
| 작다 (0.1%) | 잔 조각이 더 남는다. 굽다리바리에서 유지 조각 4 → 7개 |
| 크다 (0.5%+) | 진짜 채움의 작은 덩어리까지 버릴 위험 |

측정 (굽다리바리 guide8, τ 0.6 고정):

```
섬 0.1% → 채움 846,933 면 · 유지 조각 4 / 123
섬 0.2% → 채움 844,593 면 · 유지 조각 3 / 121      ← 채택. 차이 2,340 면 (0.3%)
```

**추천 0.1 ~ 0.3%.** 이 값은 결과를 크게 바꾸지 않는다 — 부스러기만 걸러 낸다.

## 8. 결 이웃 수 k · 결 세기 (질감)

두 값은 `blend` 방식에서만 쓴다. 채움부 색을 이렇게 만든다:

```python
smoothed = rgb_obs[이웃 k개].mean()     # 원본 표면을 국소 평균 → 얼룩·톤이 여기 남는다
detail   = rgb_obs - smoothed          # 남은 것 = 태토 결·물레 흔적 (고주파)
채움색   = 높이대_톤(h) + 세기 × detail[고른 정점]
```

### k — 무늬의 크기

k 는 '결'을 뽑을 때 평활에 쓰는 이웃 정점 수다. **크면 평활 반경이 넓어져 잔차에 저주파(얼룩)가
섞이고, 무늬가 굵어진다.**

측정된 평활 반경 (원본 정점 154,971개 기준, 물체 최대 변에 대한 비율):

| k | 평활 반경 | 채움 색 표준편차 (R) |
| --- | --- | --- |
| 24 | 1.13% | 26.8 |
| 48 | 1.57% | 28.6 |
| 96 | 2.16% | 30.7 |
| 192 | 2.93% | 33.3 |
| 384 | 3.97% | 36.5 |

(원본 실측의 표준편차는 **40.5** — k 384 에서 거의 닿는다)

> k 96 이상이면 무늬 크기가 물레 흔적 간격(약 2%)을 넘어, 결이 아니라 **별개의 요철 층**으로 보인다.

### 세기 — 얼룩의 짙기

표준편차를 지배하는 값이다 (k 24 고정, R 채널):

| 세기 | 표준편차 | 모습 |
| --- | --- | --- |
| 0.3 | 18.7 | 거의 매끈 |
| 0.5 | 19.7 | 얼룩 없이 태토 결 |
| 0.8 | 22.1 | 결이 보인다 |
| 1.2 | 26.8 | 결이 도드라진다 |
| 1.6 | 32.2 | 짙은 줄이 보인다 |
| 2.0 | 37.8 | 원본 실측(40.5)과 같은 수준 · 검붉은 얼룩이 뭉치기 시작 |
| 2.5 | 44.9 | 원본보다 얼룩짐 |
| 3.0 | 51.3 | 갈색 덩어리 (원본의 1.27배) |

채택 조합 **k 12 · 세기 0.8** 의 실측: 표준편차 [21.4, 22.8, 22.9] · 평균 RGB [154.2, 147.5, 135.8].

### 두 값의 역할이 다르다

| | 올리면 |
| --- | --- |
| **세기** | 얼룩이 **짙어진다** — 흙얼룩·그을음이 강하게 옮겨 온다 |
| **k** | 무늬가 **굵어진다** — 톤은 창백한 채로 유지된다 |

**k 384 · 세기 1.2** 는 표준편차 36.5 로 세기 2.0(37.8)과 비슷하지만 **갈색 덩어리가 없다** —
같은 변동량을 얼룩 없이 얻는 조합이다.

### 반드시 같이 말해야 하는 것

> 값을 올려서 늘어난 변동은 **그 자리의 실제 표면이 아니다.**
> 원본 파편의 실제 흙얼룩이 맞지만, **그 얼룩이 있던 자리는 다른 각도**다.
> 눈에는 질감으로 읽히지만 "이 자리가 원래 이렇게 생겼다"는 근거가 없다.
> 실측 근거가 중요한 자리에는 `TEXMODE=band` (높이대 톤만, 합성 무늬 없음) 를 쓴다.

**추천**: 자연스러움 우선이면 **k 6 · 세기 0.5**, 질감을 도드라지게 하려면 **k 12~24 · 세기 0.8~1.2**.

## 9. 그 밖의 파라미터

### 9-1. 가이드 이미지 — 가장 영향이 크다

파라미터라기보다 입력이지만, 결과를 가장 크게 바꾼다.

| 가이드 | 채움 (원본 면적) | 테두리 | 투창 |
| --- | --- | --- | --- |
| guide7 (610×666) | 56.9% | 단 남음 | **뚫림 (창 2개)** |
| guide8 (1015×1129) | 70.9% | 고름 | 메워짐 (창 0개) |

**채움이 많을수록 좋은 게 아니다.** 늘어난 14%p 가 채워야 할 결손이 아니라
**뚫려 있어야 할 투창**을 덮었다.

### 9-2. 시드

`--seed`. 1단계 복셀은 **결정적**이지만(SHA256 동일), 2단계는 아니다 —
같은 가이드·같은 시드로 다시 돌렸을 때 면 수가 1,114,620 → 1,114,688 (+68, 0.006%) 로 달랐다.
**보이는 결과는 같다.** 다른 결과를 원하면 시드를 바꿔야 한다.

### 9-3. IAS 반복 횟수

`--optimization-step`. 0 = 끔 · **1 = 채택** · 2 이상 미시도.
1 로 올리면 피크 +318 MiB · 소요 +55%. 테두리 정렬이 더 나아질 여지가 있으나 확인하지 않았다.

### 9-4. 양자화·메모리

`LASCOMP_QUANT=fp8` · `LASCOMP_OFFLOAD=1` · `LASCOMP_MESH_CPU=1` · `LASCOMP_DECODE_LEAN=1`.
→ [양자화내용 수치로 비교.md](양자화내용%20수치로%20비교.md)

### 9-5. 질감 방식

`TEXMODE` = `blend`(채택) · `band`(톤만) · `mirror`(실측 색 그대로).
`--tint 1.06,1.02,0.98` 로 채움부에만 색조를 곱해 복원부를 **구분 표시**할 수 있다
(박물관 관행은 복원부를 일부러 구분해 보이는 쪽이다).

### 9-6. 합치기 경계

`hybrid_fill.py --split auto` — 세로축 둘레 반지름이 가장 좁아지는 높이.
굽다리바리에서 bbox 높이의 **0.383**.

## 10. 파라미터가 **못 하는** 것

**투창(뚫린 창)을 지키게 할 수는 없다.**

LaS-Comp 의 ERS 는 이 한 줄이다:

```python
pred_voxel[voxel_mask] = 1.0      # 관측 복셀을 1 로만 만든다
```

한쪽 방향뿐이다 — "관측된 표면은 지켜라"는 있고 **"여기는 비어 있어야 한다"는 장치가 없다.**
게다가 투창은 64³ 격자에서 **폭 2~3칸**뿐이라, 벽이 조금만 두꺼워지면 FlexiCubes 가 이어 버린다.

τ·섬 임계는 **완성된 메시의 후처리**라 되살릴 수 없다 — 실측으로도 확인했다
(섬 0.1% → 0.2% 로 바꿔도 창 0개 그대로).

쓸 수 있는 손잡이는 셋뿐이다:

| 손잡이 | 성격 |
| --- | --- |
| 가이드 이미지 | 가장 큼 |
| 시드 | 확률적 — 돌려봐야 안다 |
| `hybrid_fill.py` 높이 필터 | 굽다리를 채움 대상에서 빼면 **원본의 실제 투창이 남는다** ← 확실한 방법 |
