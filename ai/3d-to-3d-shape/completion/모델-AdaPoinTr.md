## 1. 무슨 모델인가

**Point Cloud Completion** — 부분 점군 → 완성 점군.

| | |
| --- | --- |
| 입력 | 점 2,048개의 (x, y, z). **색도 법선도 메시도 안 받는다** |
| 출력 | 점 8,192개의 (x, y, z) — ShapeNet-55 설정 |
| 과제 정의 | 집합 → 집합 번역 (set-to-set translation) |
| 학습 데이터 | ShapeNet-55 — 55개 분류, 약 4.2만 형상의 CAD 모델 |

**"어디가 결손인지"를 알려주는 입력 통로가 없다.** 모델이 형상만 보고 스스로 판단한다.
이것이 우리 파이프라인과 어긋나는 첫 지점이다 — 우리는 결손 판정을 따로 해서 마스크를 갖고 있다.

## 2. 구조 — 다섯 단계

![모델 구조](images/모델-구조.png)

### ① 포인트 프록시로 바꾼다

트랜스포머는 토큰 열을 먹는데 점군은 순서가 없다. 그래서 **점을 묶어 토큰으로 만든다.**

1. **FPS** (Furthest Point Sampling) — 서로 최대한 멀리 떨어지도록 중심점 N개를 고른다
2. 각 중심 주변을 **경량 DGCNN** 으로 훑어 국소 특징을 뽑는다
3. 위치를 더한다 — `Fᵢ = F'ᵢ + φ(pᵢ)` (`φ` 는 MLP)

> **프록시 하나 = 점 하나가 아니라 국소 패치 하나**다. 이게 뒤에서 중요해진다.

### ② geometry-aware 트랜스포머 인코더

보통의 self-attention 옆에 **kNN 국소 집계**를 나란히 붙인다.

```
ϕ(Vᵢ) = M( Linear([Vᵢ, Vⱼ − Vᵢ]) ),   j ∈ κ(pᵢ)     ← κ = kNN 이웃
```

이웃과의 **차이 벡터**를 같이 넣어 max-pool 한다. 전역 attention 만으로는 놓치는
국소 기하(면의 굴곡·두께)를 살리려는 것이다. 이건 PoinTr 에도 이미 있었다.

### ③ 쿼리 생성 — ★ AdaPoinTr 가 바꾼 곳 ①

디코더가 채워 넣을 **"빈칸 토큰"** 을 만드는 단계다.

| | PoinTr (2021) | **AdaPoinTr** |
| --- | --- | --- |
| 방식 | 인코더 출력을 선형 사영해 좌표를 만들고 MLP 로 임베딩 | **쿼리 뱅크** `Q_I ∪ Q_O` 를 만들고 경량 scoring 모듈이 **top-M 을 적응 선택** |
| `Q_I` | — | 입력 프록시에서 추출한 것 |
| `Q_O` | — | **결손 프록시의 초기 상태로 생성한 것** |

"adaptive" 가 여기서 나온다. 결손 정도가 제각각인 입력에 쿼리 수를 맞춰주는 것이 목적이다.

### ④ 디코더

쿼리를 인코더 출력에 교차 참조시켜 **결손 영역의 프록시**(중심좌표 `cᵢ` + 특징 `Hᵢ`)를 만든다.

### ⑤ FoldingNet 형 복원 헤드

프록시 하나를 점 여러 개로 편다.

```
Pᵢ = f(Hᵢ) + cᵢ
```

`f` 는 2D 격자를 3D 패치로 접는 FoldingNet 식 함수다. **`cᵢ` 주변 몇 mm 규모**를 만든다.

> ### 여기가 이 문서의 핵심이다
>
> **점은 프록시 중심 `cᵢ` 주변에만 생긴다.** `f` 가 수 cm 떨어진 결실부로 건너뛰지 않는다.
> 그래서 사슬이 이렇게 된다:
>
> ```
> Q_O 중심이 결손부에 안 찍힘
>   → 디코더 프록시가 결손부에 없음
>     → 복원 헤드가 결손부에 점을 만들 자리가 물리적으로 없음
> ```
>
> 기여자 08-28 의 **"결실 하부로 나간 출력점 0점"** 이 정확히 이 서명이다.
> 모델이 *복원을 못 한* 게 아니라 **`Q_O` 중심을 전부 관측 표면 위에 찍은** 것이다.

## 3. 어떻게 예측하나 — 사전학습이 전부다

**모델은 추론하지 않는다. 기억한 분포에서 꺼낸다.**

```
인코더가 입력 형상을 특징으로 압축
        ↓
  "이 형상은 학습 분포의 어디쯤인가"
        ↓
  Q_O 중심좌표 ← 가중치가 답한다:
                 "이런 특징일 때 결손 중심은 대개 여기 있더라"
```

가진 것은 **4.2만 형상을 보며 익힌 "부분 → 전체" 대응표**뿐이다.
물리도, 회전대칭도, 도자기 지식도, "이게 깨진 것"이라는 개념도 없다.

**그래서 08-28 이 실패했다.** 바닥 없는 돔을 넣으면 ShapeNet 분포에서 가장 그럴듯한
완형은 **사발**이다. 모델은 자기 분포에서 정답을 냈다. 그 분포가 유물 분포가 아닐 뿐이다.

> 로드맵 §2.1 에 적어둔 *"어떤 completion 모델도 '이것이 전체인가 일부인가'를
> 형상만으로 판별하지 못한다"* 가 이 얘기다.

## 4. 어떻게 학습하나

### 4.1 사전학습 — 저자가 이미 했다

| | |
| --- | --- |
| 누가 | **논문 저자.** 우리는 가중치 파일(`.pth`)만 받는다 |
| 무엇으로 | ShapeNet-55 (55분류 4.2만 형상) 또는 PCN (8분류) |
| 쌍 만드는 법 | 완형 CAD 를 **가상 카메라 시점에서 잘라** 부분 점군을 만든다 |

**사전학습이 없으면 예측이 불가능하다.** 예측 능력이 100% 가중치에 있다.
초기화 상태로 돌리면 난수가 나온다.

> 08-28 의 *"파인튜닝 없음"* 은 **사전학습을 안 했다는 뜻이 아니라**,
> 받아온 가중치를 우리 도메인(토기)에 맞춰 추가 학습하지 않았다는 뜻이다.

### 4.2 손실

```
J_PC = J₀ + J₁ + λ · J_denoise
```

| 항 | 무엇 | |
| --- | --- | --- |
| `J₀` | 프록시 중심좌표의 **Chamfer 거리** | 거친 단계 |
| `J₁` | 최종 점군의 Chamfer 거리 | 조밀 단계 |
| `J_denoise` | ↓ 4.3 | **AdaPoinTr 에서 추가** |

Chamfer 거리는 두 점집합의 양방향 최근접 거리 평균이다.

```
CD(C, G) = 1/|C| Σ_c min_g ‖c−g‖  +  1/|G| Σ_g min_c ‖g−c‖
```

`CD-ℓ₁` / `CD-ℓ₂` 는 안쪽 노름을 L1 로 쓰냐 L2 로 쓰냐의 차이다.

### 4.3 denoising 보조 과제 — ★ 바꾼 곳 ②

학습을 안정시키려고 **일부러 흐트러뜨린 쿼리를 같이 넣고 되돌리게** 시킨다.

1. 정답 중심점에 노이즈를 더해 가짜 쿼리를 만든다 — `ĉᵢᵍᵗ = nᵢ + cᵢᵍᵗ`
2. attention 마스크로 정답이 새는 것을 막는다 — `m_ij = 0  (qᵢ ∈ Q̂, qⱼ ∈ Q)`
3. 거기서 원래 형상을 복원하게 한다

효과가 **학습 시간 15배 단축**이다. 성능이 아니라 **수렴 속도**가 핵심 이득이다.

> **이건 학습 전용이다. 추론 경로에 존재하지 않는다.**
> 그래서 우리가 [1][2] 에서 추론만 돌릴 때는 PoinTr 와 코드 경로가 같다.
> — 기여자 스크립트가 그대로 붙는 이유이기도 하다.

### 4.4 실제로 파인튜닝한 설정 — v3

**착수 때는 *"파인튜닝한다면"* 이었다. 실제로 세 번 돌렸다** (v1 → v2 → v3).

| 항목 | 착수 때 계획 | **실제 (v3)** |
| --- | --- | --- |
| 데이터 | 완형 9점 × 4패턴 | **완형 16형상 × 6패턴 × 20 = 1,920쌍** |
| 분할 | — | **형상 단위** 학습 14 / 검증 2 (+ 테스트 3형상 360쌍) |
| 배치 | batch 1~2 + checkpointing | **배치 2 × 누적 8 · AMP** |
| lr | — | **1e-5** |
| 손실 | — | 순수 PyTorch CD-L1 (CUDA 확장 없이) |
| **채택 기준** | — | **결손부 커버리지 이득.** val CD 아님 — 입력을 베끼면 CD 가 좋게 나온다 |
| 결과 | — | `AdaPoinTr_gupdari_v3.pth` · **ep8** · 14에폭 조기종료 · **75분** |

**인코더는 안 얼렸다.** 얼리는 쪽이 과적합에 낫다고 봤는데, 실제로는 안 얼려도
과채움 대조군(`none` 쌍)에서 보충점이 9개뿐이라 문제가 안 됐다.

| 항목 | |
| --- | --- |
| 쌍 구성 | **`none`(완형→완형)을 반드시 섞는다.** 빼면 "입력은 항상 부족하다"를 배워 과채움 |
| 시작점 | ShapeNet-55 가중치에서 이어서 (scratch 아님) |
| **정규화** | **자기 정규화.** `complete` 기준으로 하면 모델이 크기를 액자에서 읽는다 (§4.5) |
| 쌍 구성 | **`none`(완형→완형)을 반드시 섞는다.** 빼면 "입력은 항상 부족하다"를 배워 과채움 |
| 시작점 | ShapeNet-55 가중치에서 이어서 (scratch 아님) |
| 8GB 현실 | 공식 설정 batch 48 → **batch 1~2 + gradient checkpointing** |
| 옵션 | 인코더를 얼리고 디코더+헤드만 학습하면 표본이 적을 때 과적합이 덜하다 |

**형상 다양성이 근본 한계다.** 9 → 19 로 늘렸지만 증강으로 쌍 수는 늘어도
형상은 안 는다. 모델이 배우는 건 사실상 *"굽다리바리는 이 19개 중 하나처럼 생겼다"* 이고,
**그건 S11(참고유물 프로파일)이 학습 없이 주는 prior 와 같은 prior** 다.
차이는 S11 은 "3번 참고품에서 가져왔다"를 기록하고, 파인튜닝 모델은 가중치에 녹여
**추적이 불가능**해진다는 것뿐이다.

## 7. 실행할 때 바꿀 곳

기여자 `restore_standalone.py` 가 CUDA 확장을 순수 PyTorch 로 갈아끼워 두었다
(`_furthest_point_sample` · `_gather_operation` · `_three_nn` · `_three_interpolate` ·
`_grouping_operation` · `_ball_query`). `models` import 전에 `sys.modules` 에 등록하는
방식이라 **모델 코드를 안 고친다.**

| | 현재 (PoinTr) | 바꿀 것 |
| --- | --- | --- |
| 모델 | `from models.PoinTr import PoinTr` | `from models.AdaPoinTr import AdaPoinTr` |
| 설정 | `cfgs/ShapeNet55_models/PoinTr.yaml` | `cfgs/ShapeNet55_models/AdaPoinTr.yaml` |
| 가중치 | `pretrained/pointr_shapenet.pth` | AdaPoinTr ShapeNet-55 체크포인트 |
| 입력 | `load_las(path)` | `np.load(npz)["partial"]` — LAS 우회 ([2] 한정) |

추론 호출부 `coarse, fine = model(x)` 는 그대로다.
**유일한 미지수는 geometry-aware 블록의 kNN 에서도 대체가 먹느냐**인데, 돌려봐야 안다.

## 8. 용어

| 말 | 뜻 |
| --- | --- |
| **포인트 프록시** | 점 하나가 아니라 국소 패치 하나를 대표하는 토큰 |
| **FPS** | Furthest Point Sampling. 서로 멀리 떨어지게 중심점을 고르는 법 |
| **쿼리** | 디코더가 채워 넣을 "빈칸 토큰" |
| **`Q_O`** | 결손 프록시의 초기 상태. **결손부 점의 유일한 출처** |
| **Chamfer 거리(CD)** | 두 점집합의 양방향 최근접 거리 평균 |
| **FoldingNet 헤드** | 2D 격자를 3D 패치로 접어 프록시 하나를 점 여럿으로 펴는 것 |
| **사전학습 / 파인튜닝** | 저자가 ShapeNet 으로 한 것 / 우리가 토기로 이어서 하는 것 |
| **보충점** | 출력점 중 입력에서 멀리 떨어진 것 = 모델이 새로 만든 점 |
