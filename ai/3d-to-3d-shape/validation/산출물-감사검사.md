# 최종 산출물 감사 검사

## 정정된 결론

dev에는 이미 결과 비교·평가 기능이 있다.

- `completion/eval_completion.py`: 결손부 커버리지 순증과 Chamfer
- `completion/versions.py`: 메시 버전별 이면각·프로파일·색·이음새 비교
- `rotational/build_mesh_direct.py --fill-compare`: 채움 평활도 비교
- `rotational/compare_material.py`: Lab 색차와 질감 비교
- `rotational/render_check.py`: 사진 시점 실루엣 IoU

따라서 별도의 범용 prediction/evaluation 계약을 포팅하지 않는다. `_pedestal_dev_staging`은
참고 구현으로만 남기고, 현재 dev에서 부족한 **최종 원본 불변 자동검사와 실행 해시**만 최소
추가한다.

## `audit_result.py`가 하는 일

1. 입력 GLB와 최종 GLB의 `region_observed`를 같은 working coordinate space로 읽는다.
2. 정점 좌표와 face 배열이 동일한지 검사한다.
3. `region_observed`가 없으면 기존 대조군 이름인 `region_carried`를 확인한다.
4. 입력·결과·설정 파일의 SHA-256을 기록한다.
5. 독립 GT를 주지 않으면 `NOT_EVALUATED_NO_INDEPENDENT_GT`라고 명시한다.

이 검사는 품질 점수를 다시 계산하지 않는다. `PASS`는 “원본 관측 형상을 바꾸지 않았다”는
뜻이지 “소실부를 정확하게 복원했다”는 뜻이 아니다.

## 실행

```powershell
python audit_result.py `
  --source A_normal.glb `
  --result A_normal_2node.glb `
  --config run-config.json `
  --out A_normal_2node.audit.json
```

대조군처럼 노드 이름을 직접 지정할 수도 있다.

```powershell
python audit_result.py `
  --source A_normal.glb `
  --result restored_direct.glb `
  --observed-node region_carried `
  --out restored_direct.audit.json
```

## 판정

| 항목 | dev 적용 |
|---|:---:|
| 범용 prediction 계약과 외부 solver adapter 전체 | X |
| 기존 평가기 재구현 | X |
| 입력·결과·설정 해시 | △ |
| 최종 관측 노드 정점·face 불변 검사 | △ |
| 독립 GT가 없는 실제 유물의 상태 표시 | △ |

발표에는 새로운 AI 기술로 넣지 않고, 필요하면 “원본 보존 검증” 한 줄로만 사용한다.
